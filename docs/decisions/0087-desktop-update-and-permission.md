# 0087：从正式 GitHub Release 安装桌面更新

2026-11-17。接受，发布链路待签名试装。

在「设置 → 更新」手动检查或安装更新。Apple Silicon 构建只有内置发行公钥才启用；使用 Tauri updater 校验包和签名中的版本，限定为项目 GitHub 正式 Release 的同版本资源。用户确认后下载，安装前再次检查在线、离线、导出和下载任务状态；应用重启时继续读取原用户数据。保留 DMG 作为首次安装、旧版本迁移和恢复的入口。没有采用运行中替换文件或下载后直接执行脚本的方式。

发行签名仅认证更新包。ad-hoc macOS 签名的身份仍可能随构建变化，因此在「使用说明」提醒系统音频可能需要重新授权。已在原安装包验证重置旧 AudioCapture 授权后，同版本正常退出重开不再提示；未验证跨版本授权继承。具体产物与试装见[发布说明](../releasing.md#应用内更新)。
