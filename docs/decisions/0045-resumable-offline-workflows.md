# 0045：可恢复识别与冻结的处理配置

日期：2026-10-18

状态：accepted，分阶段实现

长节目由应用层规划约 120 秒输出区间，前后各最多 5 秒音频上下文。每块证据校验并原子提交后才能进入完成进度；中断保留完成块，在同一任务内手动恢复，保留每次尝试。CPU 回退只影响当前及后续块，不重新计算此前完成块，也不自动上传云端。

识别配置、资源内容身份和切块策略冻结；不同内容或语义配置不能复用检查点。部分产物只读，完整结果发布采用事务和冲突保护。旧任务不能伪造检查点。文件是检查点证据，SQLite 是可重建索引。

翻译选择分为全局默认、任务偏好和不可变执行快照；批量运行不能随着全局设置改变后端。凭据不进入快照。选择翻译后默认识别完成即翻译，翻译恢复不重做识别。

设置、候选比较、搜索、循环试听、批量预设和学习导出按既有离线定位扩展。MLX 仅进入隔离 CLI 对照实验，通过质量和发行门禁前不替换桌面 runtime。

替代方案：整片进程重试实现简单，但长任务失败丢失过多计算；从日志截取前缀无法证明输出完整性；静默自动云端回退改变隐私边界，均不采用。
