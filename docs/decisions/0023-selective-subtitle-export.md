# 0023：字幕文件按用途选择导出

日期：2026-08-14

## 状态

已采纳。

## 背景

旧界面每次固定导出原文 SRT、译文 SRT、双语 SRT 和双语 ASS。批量识别后统一翻译、只交付某一种播放器格式等场景会产生无用文件，而且旧的全局译文校验让尚未翻译的任务连原文 SRT 也无法独立导出。

## 决策

- 导出前由用户勾选原文 SRT、译文 SRT、双语 SRT、双语 ASS，可多选，默认全选以保持旧习惯。
- 冲突预览和覆盖确认只计算本次选中的文件。
- 原文 SRT 只依赖已保存的原文和时间轴，可在译文缺失或过期时独立导出。
- 译文 SRT 和双语格式要求所有字幕段已有最新译文，避免悄悄输出残缺成品。
- 不增加原文 ASS、译文 ASS 等没有当前真实需求的组合。

## 结果

应用层以明确的导出产物枚举接收选择，桌面 UI 不再把四文件捆绑视作唯一操作。任务目录中的派生字幕仍然只是 SQLite 当前工作区的投影，不成为编辑数据源。
