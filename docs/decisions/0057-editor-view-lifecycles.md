# 0057：编辑视图与工具的生命周期边界

日期：2026-10-21

状态：已采纳；用户同意在保留性能观察项的同时进入第三阶段，逐条抽取边界。

## 决策

`current-cue-editor.ts` 负责当前段双语输入、IME、按钮状态和输入监听器。它直接使用会话已有的 SubtitleDrafts，不创建第二份保存队列或 dirty 状态；编辑内容、失败重试与草稿恢复继续由原服务持有。视图通过选中段查询、撤销和状态回调访问用例，通过 AbortController 释放监听器。

`editor-backend.ts` 集中适配文字保存、文字恢复与时间保存，`editor-types.ts` 定义对应字幕数据。适配层保持原 Tauri 请求形状与后端校验；视图和编辑会话不直接导入 Tauri。其余调用随用例抽取逐步迁入，不能把存在一个适配文件视为所有调用已经收敛。

`task-tools.ts` 负责翻译／导出任务区域与识别复核 dialog 的连接、卸载和焦点边界。模块使用固定锚点，按需连接一份表单实例；关闭后移入模块持有的 DocumentFragment，保留尚未提交的工具输入。页面退出时释放模块监听器与锚点。工具模板独立于 main.ts；进行中任务仍可复用该区域显示只读进度。

识别复核信号的模型仍供列表筛选使用；提示条目只在复核工具打开时创建，关闭后释放，旧请求返回时仍核对任务身份与工具打开状态。虚拟列表和播放器不因工具开关而重建。WKWebView 的任务工具继续使用具名 region 和受限焦点，识别复核同样使用非模态具名区域，并显式禁止背景交互、限制 Tab 和支持 Escape；候选对照在后续原生验证中也改为同一显式焦点边界，见 0058 的原生补充；导出在 2026-10-23 按下文改为同一显式焦点边界；通用确认仍保留既有原生模态调用，相关可访问性限制单独记录。

## 限制与后续

表单实例会预先构造并在卸载时保留，当前实现减少连接的隐藏 DOM 与复核条目，不代表首次模块加载、全部控件实例和模型内存都已延迟分配。不会为追求零实例而复制表单或改变保存语义。

播放器、时间轴手势／绘制、处理用例及会话协调仍有代码留在 main.ts；后续逐条抽取并回归。Rust 命令层与 repository 另行拆分，不借前端整理修改数据库事务。长时内存、滚动帧和 Windows 实机回归继续保留为性能验收项，与模块抽取分别记录。

## 原生验证补充

按需连接后的识别复核 `showModal()` 在 WKWebView 隐藏所有 AX 控件，已改为非模态具名区域加明确的背景 inert 和焦点约束。原生窗口实际显示范围、provider、复核与关闭控件，Escape 后恢复编辑。没有通过关闭系统可访问性来绕过问题。

## 2026-10-23：字幕文件导出边界

`subtitle-export.ts` 持有一次导出意图、结果路径与请求代次；任务 ID 和 navigation 在打开时冻结，每次 await 后核对。reset／dispose 取消等待选择、失效旧返回，并只释放自己占用的 busy 状态。草稿、翻译完整性和过期提示沿用原逻辑；后端继续负责实际文件冲突、字幕状态与写入校验。`subtitle-export-backend.ts` 集中四条原 IPC，字段与命令名不变，DTO 独立于视图。

`subtitle-export-view.ts` 持有格式选择和导出专用覆盖确认各一份节点，关闭即移出文档，dispose 释放监听器和焦点边界。复用 mountToolDialog 的具名 region、背景 inert、Tab 循环、Escape 和关闭焦点恢复，不再借用通用 confirmation-dialog；文件名用 textContent 呈现。main.ts 仅注入当前任务、原草稿查询、全局 busy 和消息回调，不增加播放器或保存状态。

原生 QA 验证格式控件 AX、勾选、系统目录取消、Escape 回到导出按钮与返回原编辑段；系统目录面板 Open 禁用，原生文件写入和覆盖确认尚未验收。WebKit mock 覆盖格式、覆盖确认／取消、焦点及重试；会话测试覆盖切任务与 dispose 后的迟到返回。这些证据不替代实际原生文件导出或 Windows 验证。
