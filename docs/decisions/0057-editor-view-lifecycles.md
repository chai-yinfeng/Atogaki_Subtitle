# 0057：编辑视图与工具的生命周期边界

日期：2026-10-21

状态：已采纳；用户同意在保留性能观察项的同时进入第三阶段，逐条抽取边界。

## 决策

`current-cue-editor.ts` 负责当前段双语输入、IME、按钮状态和输入监听器。它直接使用会话已有的 SubtitleDrafts，不创建第二份保存队列或 dirty 状态；编辑内容、失败重试与草稿恢复继续由原服务持有。视图通过选中段查询、撤销和状态回调访问用例，通过 AbortController 释放监听器。

`editor-backend.ts` 集中适配文字保存、文字恢复与时间保存，`editor-types.ts` 定义对应字幕数据。适配层保持原 Tauri 请求形状与后端校验；视图和编辑会话不直接导入 Tauri。其余调用随用例抽取逐步迁入，不能把存在一个适配文件视为所有调用已经收敛。

`task-tools.ts` 负责翻译／导出任务区域与识别复核 dialog 的连接、卸载和焦点边界。模块使用固定锚点，按需连接一份表单实例；关闭后移入模块持有的 DocumentFragment，保留尚未提交的工具输入。页面退出时释放模块监听器与锚点。工具模板独立于 main.ts；进行中任务仍可复用该区域显示只读进度。

识别复核信号的模型仍供列表筛选使用；提示条目只在复核工具打开时创建，关闭后释放，旧请求返回时仍核对任务身份与工具打开状态。虚拟列表和播放器不因工具开关而重建。WKWebView 的任务工具继续使用具名 region 和受限焦点，识别复核同样使用非模态具名区域，并显式禁止背景交互、限制 Tab 和支持 Escape；候选对照在后续原生验证中也改为同一显式焦点边界，见 0058 的原生补充；导出在 2026-10-23 按下文改为同一显式焦点边界；通用确认仍保留既有原生模态调用，相关可访问性限制单独记录。

## 限制与后续

表单实例会预先构造并在卸载时保留，当前实现减少连接的隐藏 DOM 与复核条目，不代表首次模块加载、全部控件实例和模型内存都已延迟分配。不会为追求零实例而复制表单或改变保存语义。

播放器、时间轴手势／绘制、处理用例及会话协调仍有代码留在 main.ts；后续逐条抽取并回归。Rust 命令层与 repository 另行拆分，不借前端整理修改数据库事务。长时内存、滚动帧和 Windows 实机回归继续保留为性能验收项，与模块抽取分别记录。

## 原生验证补充

按需连接后的识别复核 `showModal()` 在 WKWebView 隐藏所有 AX 控件，已改为非模态具名区域加明确的背景 inert 和焦点约束。原生窗口实际显示范围、provider、复核与关闭控件，Escape 后恢复编辑。没有通过关闭系统可访问性来绕过问题。

## 2026-10-23：翻译会话与活动计时

`subtitle-translation.ts` 持有单句／批量用例、每任务活动和唯一进度 timer；`subtitle-translation-backend.ts` 集中原 `translate_subtitle`、`translate_all_subtitles`、`get_job_detail` 三条 IPC，参数与后端实现不变。main 注入唯一 SubtitleDrafts 的 flush／dirty、现有确认视图和工作区结果回调。确认阶段也预留任务活动，避免重复提交；确认返回后再次检查草稿和任务可用状态。

每次调用冻结任务 ID、navigation 与 provider 展示信息，每次 await 后核对。单句保存失败不发翻译，切页发生在 flush 期间也不追加请求；已发出的后台翻译仍可正常落库，离开后重进同任务不能让旧结果覆盖新视图。批量失败继续读取已经成功的批次，明确提示续译；错误恢复读取本身迟到时也不覆盖另一视图消息。不同任务的活动独立结束，dispose 停止 timer 并忽略所有迟到呈现，不声称取消后端工作。

进度不再按固定 12 段估算批数。现有后端按语义分组与 provider 限制组织请求，界面显示段数和成功批次会立即保存，完成后报告服务实际返回的计数。后端 revision 校验、候选事务、翻译配置和通用确认的原生模态实现不在本次改动中。

## 2026-10-23：统一过期预检与真实取消验收

长任务原生验收发现，文字过期 flag 与上下文依赖过期是两种信号；烧录入口只统计前者，会打开工具后才由 export_ass_snapshot 拒绝。`subtitle-translation-state.ts` 集中纯状态判断，按实际 cue ID 合并两者并去重，导出／烧录预检复用，翻译待处理判断保持原语义。仅原文 SRT 仍不依赖译文新鲜度；后端 revision 与最终过期校验不变，预检只使用当前已加载的工作区状态，不替代后端校验。

原生隔离长任务确认 1 段文字过期＋45 段上下文过期在入口提示 46 段，未打开烧录工具。随后仅对既有隔离副本临时清除这两类标记，实际启动 1080p 长视频，在约 1% 时确认取消；原生历史和数据库进入 cancelled，FFmpeg 退出，最终输出不存在、partial 清理。全部字幕、provenance、依赖边与样式在退出后恢复核对，不能把测试夹具状态当成旧译文质量已通过。

## 2026-10-23：全局配置保存会话

`desktop-settings-save.ts` 负责单个冻结保存请求、防重复、访问代次、提交后的 profile／任务状态刷新和 dispose；`desktop-settings-backend.ts` 适配既有 `save_desktop_settings` 与 `translation_profiles`，DTO 移到 `desktop-settings-types.ts`。输入读取和呈现仍由 main 注入，不将保存会话抽取视为完整设置视图已经迁移。

原 dirty Set 由单份带版本 registry 取代；保存前取得字段与 provider 的版本快照，只确认版本未变化的已提交字段、仅确认本次 provider。保存中继续输入，即使输入值与先前相同也保留 dirty；换 provider 不会误清新 provider 草稿。只有完成首次配置且没有新增输入、状态刷新成功时才自动关闭。按钮禁用期间防止重复请求，返回时只在原访问仍打开、焦点落 body 且用户未转移输入焦点时恢复键盘提交按钮。

读取设置仍在 main，但附带访问与请求代次；保存开始和接受结果时失效旧读取，避免保存前的返回覆盖新状态。关闭重开不呈现旧保存的消息／值，若其后端写入完成则重读当前访问，并继续保留该访问的 dirty。凭据只经原保存请求交给系统服务，不存入会话字段、profile 草稿、日志或新增持久化。关闭仅失效前端呈现，不取消后端已发出的写入。

配置整体视图、provider 卡片事件、独立凭据操作、模型下载／卸载和网络测试仍在原处；它们的请求与新输入保护需随各自边界另行整理，本次不承诺其异步行为全部完成。

## 2026-10-24：provider 操作用例与 IPC 边界

`translation-provider-actions.ts` 接管卡片检查、显式连接测试、保存／删除及后续状态刷新；`translation-provider-backend.ts` 适配原五条 IPC，DTO 独立。main 只注入输入快照确认、profile 呈现和消息；视图保留按钮与焦点呈现，服务层防重复不再依赖按钮是否禁用。检查与连接测试不读取秘密输入，凭据仅在单次调用栈中捕获，不加入会话长寿命状态或缓存。

保存／删除共享会话互斥，检查／连接按操作和 provider 防重复。动作绑定设置访问及调用视图，只有最近一次操作的全局通知可以呈现；profile 读取再核对独立代次，外部已接受的配置使旧 profile 返回失效。卡片凭据写入开始和成功时失效旧设置读取，全局保存同样使旧 profile 读取失效。关闭后不触发后续读；若关闭重开时写入才结束，只为新访问读取状态，不清空新访问输入或复述旧操作消息。

凭据成功确认按输入版本及值核对；用户在等待期间重新输入相同文本也算新输入。Gemini 的 ASR 输入保持相同保护。已完成写入而后续读取失败必须准确提示；dispose 后所有迟到结果忽略，不声称取消后端调用。独立 ASR／词典凭据与全局保存／卡片保存之间的写入协调仍待各自用例抽取，不把本次卡片互斥称为所有凭据入口已统一。


## 2026-10-24：设置最终结构与公共视图

`desktop-settings-template.ts` 直接生成外观、转录、翻译、模型与存储、词典和网络六分区及唯一表单，复用静态 provider 模板。模型目录／下载／Hy-MT2 路径直接位于模型区，Gemini 局部修复位于转录区；任务的高级模型路径也直接写入 task-form 的 details。不再由页面末尾 organizeSettings 按子节点顺序猜测区域、搬移控件和追加导航；所有既有控件 ID 保持。

`desktop-settings-view.ts` 持有导航、开关、公共 input／change／submit、首次配置标题与类名、保存按钮禁用／焦点恢复和内置主题状态。按选中分区显示页面并重置内部滚动，按钮公开 aria-pressed；初始转录页有明确选中状态。用户重开沿用既有访问和读取流程，首次配置打开复用已加载结果，不再重复读取。关闭仍通知协调器失效请求并清理原 dirty 状态，未更改持久化语义。

公共监听器由 AbortController 管理，包含外部开启按钮、表单、dialog close 与 window theme 事件；dispose 先解除事件再关闭窗口，停止回调并释放焦点引用。实际字段呈现、选择文件、模型操作和 provider 草稿仍按原服务工作，没有新增配置保存逻辑。图片主题模块继续复用原外观容器，其自身监听器生命周期仍是独立后续项，本次不将它计为已清理。


## 2026-10-24：provider 草稿与字段归属

`translation-provider-drafts.ts` 取代主文件的 providerDrafts、providerDirtyDrafts、readiness 与 lastSettingsProvider：每个后端只持有 model／endpoint／style 和 dirty 版本；snapshot 只确认提交后端的同一版本，返回值复制且忽略额外字段。不存在第二份保存服务或 Key 缓存。profile 更新保留已编辑后端，同时允许当前干净后端接受迟到的已保存参数；不再借用其他后端留下的共享字段 dirty 标记决定显示。

`translation-provider-fields.ts` 负责唯一共享字段、provider 选择、输入事件与 AbortController。字段值未变化时不重新赋值；显式切换清空密码意图，每个后端从自身 profile 或自身默认值初始化端点／模型，不继承另一后端的隐藏字段。默认模型与服务地址沿用原选择逻辑，Gemini 缺失 base_url 时使用其自身默认值。默认配置读取不能改绑未保存参数或非空 Key；查看非默认后端时使用中性凭据提示，不把默认后端的凭据状态套用过去。

原公共字段 dirty registry 继续保护保存期间的新输入；provider 字段展示与非秘密草稿归本模块。关闭重开继续保留原有内存草稿，dispose 解除字段事件，Key 始终只在当前 DOM 与原单次请求中。其余设置字段、独立凭据、模型操作和图片主题仍按后续边界处理。
