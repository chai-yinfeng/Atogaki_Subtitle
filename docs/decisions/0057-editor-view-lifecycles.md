# 0057：编辑视图与工具的生命周期边界

日期：2026-10-21

状态：已采纳；用户同意在保留性能观察项的同时进入第三阶段，逐条抽取边界。

## 决策

`current-cue-editor.ts` 负责当前段双语输入、IME、按钮状态和输入监听器。它直接使用会话已有的 SubtitleDrafts，不创建第二份保存队列或 dirty 状态；编辑内容、失败重试与草稿恢复继续由原服务持有。视图通过选中段查询、撤销和状态回调访问用例，通过 AbortController 释放监听器。

`editor-backend.ts` 集中适配文字保存、文字恢复与时间保存，`editor-types.ts` 定义对应字幕数据。适配层保持原 Tauri 请求形状与后端校验；视图和编辑会话不直接导入 Tauri。其余调用随用例抽取逐步迁入，不能把存在一个适配文件视为所有调用已经收敛。

`task-tools.ts` 负责翻译／导出任务区域与识别复核 dialog 的连接、卸载和焦点边界。模块使用固定锚点，按需连接一份表单实例；关闭后移入模块持有的 DocumentFragment，保留尚未提交的工具输入。页面退出时释放模块监听器与锚点。工具模板独立于 main.ts；进行中任务仍可复用该区域显示只读进度。

识别复核信号的模型仍供列表筛选使用；提示条目只在复核工具打开时创建，关闭后释放，旧请求返回时仍核对任务身份与工具打开状态。虚拟列表和播放器不因工具开关而重建。WKWebView 的任务工具继续使用具名 region 和受限焦点，识别复核同样使用非模态具名区域，并显式禁止背景交互、限制 Tab 和支持 Escape；候选对照在后续原生验证中也改为同一显式焦点边界，见 0058 的原生补充；导出在 2026-10-23 按下文改为同一显式焦点边界；通用确认仍保留既有原生模态调用，相关可访问性限制单独记录。

## 限制与后续

表单实例会预先构造并在卸载时保留，当前实现减少连接的隐藏 DOM 与复核条目，不代表首次模块加载、全部控件实例和模型内存都已延迟分配。不会为追求零实例而复制表单或改变保存语义。

播放器、时间轴手势／绘制、处理用例及会话协调仍有代码留在 main.ts；后续逐条抽取并回归。Rust 命令层与 repository 另行拆分，不借前端整理修改数据库事务。长时内存、滚动帧和 Windows 实机回归继续保留为性能验收项，与模块抽取分别记录。

## 原生验证补充

按需连接后的识别复核 `showModal()` 在 WKWebView 隐藏所有 AX 控件，已改为非模态具名区域加明确的背景 inert 和焦点约束。原生窗口实际显示范围、provider、复核与关闭控件，Escape 后恢复编辑。没有通过关闭系统可访问性来绕过问题。

## 2026-10-23：字幕文件导出边界

`subtitle-export.ts` 持有一次导出意图、结果路径与请求代次；任务 ID 和 navigation 在打开时冻结，每次 await 后核对。reset／dispose 取消等待选择、失效旧返回，并只释放自己占用的 busy 状态。草稿、翻译完整性和过期提示沿用原逻辑；后端继续负责实际文件冲突、字幕状态与写入校验。`subtitle-export-backend.ts` 集中四条原 IPC，字段与命令名不变，DTO 独立于视图。

`subtitle-export-view.ts` 持有格式选择和导出专用覆盖确认各一份节点，关闭即移出文档，dispose 释放监听器和焦点边界。复用 mountToolDialog 的具名 region、背景 inert、Tab 循环、Escape 和关闭焦点恢复，不再借用通用 confirmation-dialog；文件名用 textContent 呈现。main.ts 仅注入当前任务、原草稿查询、全局 busy 和消息回调，不增加播放器或保存状态。

原生 QA 验证格式控件 AX、勾选、系统目录取消、Escape 回到导出按钮与返回原编辑段；系统目录面板 Open 禁用，原生文件写入和覆盖确认尚未验收。WebKit mock 覆盖格式、覆盖确认／取消、焦点及重试；会话测试覆盖切任务与 dispose 后的迟到返回。这些证据不替代实际原生文件导出或 Windows 验证。


## 2026-10-23：翻译会话与活动计时

`subtitle-translation.ts` 持有单句／批量用例、每任务活动和唯一进度 timer；`subtitle-translation-backend.ts` 集中原 `translate_subtitle`、`translate_all_subtitles`、`get_job_detail` 三条 IPC，参数与后端实现不变。main 注入唯一 SubtitleDrafts 的 flush／dirty、现有确认视图和工作区结果回调。确认阶段也预留任务活动，避免重复提交；确认返回后再次检查草稿和任务可用状态。

每次调用冻结任务 ID、navigation 与 provider 展示信息，每次 await 后核对。单句保存失败不发翻译，切页发生在 flush 期间也不追加请求；已发出的后台翻译仍可正常落库，离开后重进同任务不能让旧结果覆盖新视图。批量失败继续读取已经成功的批次，明确提示续译；错误恢复读取本身迟到时也不覆盖另一视图消息。不同任务的活动独立结束，dispose 停止 timer 并忽略所有迟到呈现，不声称取消后端工作。

进度不再按固定 12 段估算批数。现有后端按语义分组与 provider 限制组织请求，界面显示段数和成功批次会立即保存，完成后报告服务实际返回的计数。后端 revision 校验、候选事务、翻译配置和通用确认的原生模态实现不在本次改动中。


## 2026-10-23：样式请求会话

`subtitle-style-session.ts` 接管任务样式读取／保存、字体目录缓存、真实预览请求、700 ms debounce 与串行补绘；`subtitle-style-backend.ts` 适配原四条 IPC，DTO 移到 `subtitle-style-types.ts`，字段和后端实现不变。main 继续提供字体／颜色控件、报告与图像呈现，本次先抽请求边界，不将仍在 main 的字体视图称为已完成拆分。

会话绑定任务、navigation 与一次打开的代次；关闭／dispose 取消 timer，失效旧请求的成功、错误与 finally。初始读取完成前禁用未初始化参数，读取失败后不启用保存。参数修改增加草稿版本，预览仅呈现当前版本；忙时合并为一次最新补绘，保存期间的新输入不回填旧值。保存请求冻结一份参数，成功后仍有新输入时明确提示尚未保存；预览区分已保存参数与未保存草稿，不再把所有真实预览都称为未保存。

关闭时不取消后端已发出的 FFmpeg／保存调用，不增加另一份 task style 或播放器。字体选择视图、监听器与原 showModal 仍留原处；后续单独迁移视图和原生焦点边界，不能把本次会话测试外推为原生 AX、libass 渲染质量或 Windows 验收。


## 2026-10-23：样式与字体视图生命周期

后继实施将字体／颜色控件、覆盖报告、预览呈现和全部视图监听器移至 `subtitle-style-view.ts`，模板移至 `subtitle-style-template.ts`。main 仅注入任务文字／语言、文件 URL 和时间格式，连接既有样式会话；不增加草稿、字体查询服务或样式持久化副本。

视图复用 mountToolDialog 的具名 region、背景 inert、Tab 循环及返回焦点，取代上段暂留的 showModal；关闭后整组节点移出文档，字体候选收起即释放选项节点。模块使用 AbortController 释放固定控件、document 和 resize 监听器，dispose 同时关闭边界、移除节点并释放字体引用。候选选项节点随替换自然释放，不将每次重绘的节点挂到长寿命 abort signal。

Escape 在字体候选打开时先收起候选并回到字体输入，下一次 Escape 才关闭样式工具；继续输入会重新展开候选。单份会话的请求代次和参数版本保护保持不变。原生 QA 验证控件 AX、388 字体族读取、真实 FFmpeg/libass 初始预览、分层 Escape、触发按钮焦点与返回原段；仅验证本机合成任务，不能外推为所有字体、导出一致性或 Windows 通过。


## 2026-10-23：烧录工具请求与轮询会话

`video-render-session.ts` 持有一次工具访问的媒体能力、规格预估、输出选择、提交和历史；`video-render-backend.ts` 集中原七条 IPC，DTO 单列，后端队列、ASS 冻结快照和成功后替换产物的事务语义保持不变。main 暂留烧录 DOM／历史呈现和原生模态框，下一边界再迁移视图。

访问绑定任务、navigation 与打开代次；关闭后旧能力、预估、目录、历史、提交和取消返回都不能更新新视图或解锁新请求。输出路径在每次打开时清空，不继承其他任务选择。覆盖确认前预留提交状态并冻结路径／轨道／质量，确认后再核对参数和 dirty；取消确认后检查历史是否仍为可取消状态。媒体能力未知或检查失败时不启用提交，后端继续执行最终输入／冲突校验。

工具仅在打开且历史有 queued／running 时请求每秒刷新，重叠历史读取合并为同一请求，关闭／dispose 释放 timer，不再通过全局 interval 或 renderWorkspace 偷读历史。过期字幕计数仅在打开与提交校验时扫描，不进入轮询身份判断。关闭工具只结束前端观察，已提交后端工作继续正常进行；用户重开后读取真实队列状态。
