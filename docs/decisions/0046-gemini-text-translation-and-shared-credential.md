# 0046：Gemini 文本翻译与共享凭据

日期：2026-10-19

状态：accepted（用户明确要求）

桌面新增独立 `gemini` 翻译 provider，使用 Google 官方 OpenAI-compatible HTTPS 端点，复用现有字幕分组、JSON／cue ID 校验、术语保护、执行快照与可恢复翻译。默认文本模型为官方当前稳定的 `gemini-3.8-flash`，允许修改模型；音频仍使用原来的转录模型。端点固定为 Google，不能通过本任务快照把共享凭据转发到自定义服务。

两项功能共用既有系统凭据槽 `asr.gemini-transcribe` 与非秘密就绪标记，避免复制或迁移用户 Key。旧 ASR 配置直接可用；任一入口保存、替换或删除 Key 均同步缓存与就绪状态，凭据变更使翻译连接验证失效。普通启动与配置展示不读取系统凭据。UI 明确说明共享及删除的影响。

共享身份不共享授权：选择 Gemini 翻译只发送原文和文本上下文，不上传音频。ASR 仍绑定任务和确切范围逐次确认；Key 的存在不构成音频上传授权。翻译模型、风格和输入版本仍按执行冻结，不因为更换全局 provider 或模型而改变当前运行。

未采用方案：要求保存两份相同 Key 增加配置与删除歧义；将 Google 放在自定义兼容服务中会隐藏文本／音频边界。不同项目的两把 Key 本轮不增加专门入口。

官方依据：[兼容端点](https://ai.google.dev/gemini-api/docs/openai)、[模型列表](https://ai.google.dev/gemini-api/docs/models)。工程检查不代表真实云端连接与译文质量验收；没有显式样本授权不发送真实节目。
