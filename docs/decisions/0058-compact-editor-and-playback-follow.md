# 0058：紧凑字幕工作台与显式编辑锁定

日期：2026-10-21

状态：已采纳；用户确认紧凑编辑页、原译文上下排列，按交互、布局、模块边界依次实施。取代 0055 中“播放始终不切走编辑对象”和布局 v2 的默认工作区约定。

## 交互

编辑页默认跟随播放，当前段编辑框、列表播放标记随播放位置更新。单击字幕行、键盘选择、上一句／下一句、时间轴选块或聚焦编辑控件后锁定编辑对象；播放行仍独立标识。单击不定位媒体，双击或时间码定位。Cut 只能切开当前编辑段，播放头在段外时禁用；删除、连接与时间保存也作用于编辑段。

一个主“跟随播放”动作恢复编辑框、列表和波形跟随。恢复前 flush 草稿，检查 IME、保存失败及未提交时间输入；失败保持编辑对象和输入。时间输入可按 Escape 恢复。异步恢复检查任务身份、导航代次和后续编辑意图，不得覆盖等待期间的新选择或输入。

列表手动滚动只暂停列表自动滚动，不解除编辑框的播放跟随；“回到播放位置”只恢复列表滚动。编辑锁定暂停列表自动滚动。手动平移／缩放波形只暂停波形视窗跟随。筛选不因播放自动解除，播放段被过滤时编辑框仍展示该段并提示。播放空白区时，跟随模式显示无字幕；锁定模式保留编辑段。

播放行以整行浅黄色和播放符号标记，编辑段用边框标记；同一行可以同时显示两种状态。内部 cue ID、processingRange、timelineViewport 仍各自独立，自动跟随只协调展示，不把播放位置当作字幕主数据。

## 布局与风格

上方左侧为较大的媒体区域，右侧上部为波形／时间轴，下部为当前段编辑；原文与译文上下排列。下方为整宽、固定行高的虚拟字幕表格。三处分隔线调整左右比例、上方／列表比例、右侧波形／编辑比例。视频和波形可独立折叠，媒体元素不因折叠卸载。

编辑页采用独立中性色工作台，紧凑标题、统一控件和网格线。常用播放、导航、时间和文字操作常驻；翻译、词表、候选与复核按需打开。收听页保留已有视觉风格。借鉴 Aegisub 的工作区和信息密度，不引入完整 ASS 排版、多选批量处理或另一套保存模型。

布局偏好按新区域语义升级版本，旧折叠状态保留，纵向比例重新初始化。继续保留 SQLite、cue ID、revision、导出格式、草稿和撤销边界。

## 会话协调边界

`editor-follow.ts` 接管跟随意图、恢复请求代次、时间输入保护、焦点锁定及跟随状态呈现。模块通过 current／visible／flush／resumed 回调协调既有会话、草稿和播放器，不持有第二份字幕或保存队列；dispose 释放监听器并使未完成恢复请求失效。主入口保留领域操作，当前句编辑视图在输入／IME 时通知锁定。抽取后重新运行跟随专项，30 项前端测试、类型／构建与格式检查通过。


## 时间轴视图边界

`editor-timeline-view.ts` 接收可见 cue、波形、播放／编辑 ID、增益与时钟快照，只负责绘制、静态位图缓存与 ResizeObserver。播放头与播放段边框独立绘制；缓存更新／dispose 释放旧位图，dispose 断开 observer。共享 `timelineGeometry` 保证紧凑画布的字幕轨道仍在可见范围内，`timelineCueHit` 按最近边界处理相邻块的热区冲突。波形 DTO 放在 `editor-types.ts`，视图不导入 Tauri 或草稿服务。

可见范围索引、手势和波形请求仍由主入口协调，后续单独抽取；折叠后不再因播放或零尺寸 resize 请求波形。32 项单元测试、类型／构建与四组 WebKit 功能回归通过，未把这一抽取视为滚动／长时内存门禁通过。


## 时间轴手势边界

`editor-timeline-gestures.ts` 持有一次 pointer／pan／playhead／pinch 的状态、指针捕获与监听器。离开任务 reset、失去捕获、pointercancel、Escape 和 dispose 均取消未提交预览并释放捕获；拖动中阻止其他缩放手势叠加。`timeline-timing.ts` 以纯函数约束 10 ms 吸附、相邻边界及媒体范围，预览不修改主字幕数组。会话从模块读取临时预览，提交前仍 flush 原草稿并以当前文本重基，通过既有 backend 保存；任务身份和导航代次在 flush 后再次核对。

手势模块不调用 Tauri，不创建播放器、草稿或第二套持久化。34 项前端测试、类型／构建、既有四组 WebKit 回归及新增手势专项通过；专项覆盖 Escape、捕获丢失、取消后再次拖动、pan、ctrl-wheel、Safari pinch 去重、离开任务与播放头 seek。正式本机仍运行上一个已安装里程碑，后续完整构建时再更新。


## 共享播放器边界

`media-player.ts` 是编辑与收听共用的唯一媒体元素所有者，通过注入的 URL 解析、播放位置和状态回调接入应用。mount／fallback／stop／dispose 统一释放旧元素监听器、src 和 RAF；回退仍最多一次，保留位置、播放意图、音量、静音和速度。事件与迟到 play Promise 同时检查元素、挂载代次和任务身份。stop 先失效旧事件，再由会话保存旧位置，最后卸载；等待保存期间挂载的新媒体不会被旧 stop 清除。

原 WebKit 在 src 加载后会恢复默认速度；现在同时维护 defaultPlaybackRate 与 playbackRate，元数据完成后恢复配置，用户控制和原生速度变化也更新默认值。39 项前端测试、既有五组 WebKit 及共享播放器专项通过。共享播放器专项使用真实媒体事件验证回退状态、旧事件、收听恢复／保存和双源失败停止；原生最终构建仍需在后续里程碑复查。
