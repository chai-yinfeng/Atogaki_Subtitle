# 0058：紧凑字幕工作台与显式编辑锁定

日期：2026-10-21

## 交互

编辑页默认跟随播放，当前段编辑框、列表播放标记随播放位置更新。单击字幕行、键盘选择、上一句／下一句、时间轴选块或聚焦编辑控件后锁定编辑对象；播放行仍独立标识。单击不定位媒体，双击或时间码定位。Cut 只能切开当前编辑段，播放头在段外时禁用；删除、连接与时间保存也作用于编辑段。

一个主“跟随播放”动作恢复编辑框、列表和波形跟随。恢复前 flush 草稿，检查 IME、保存失败及未提交时间输入；失败保持编辑对象和输入。时间输入可按 Escape 恢复。异步恢复检查任务身份、导航代次和后续编辑意图，不得覆盖等待期间的新选择或输入。

列表手动滚动只暂停列表自动滚动，不解除编辑框的播放跟随；“回到播放位置”只恢复列表滚动。编辑锁定暂停列表自动滚动。手动平移／缩放波形只暂停波形视窗跟随。筛选不因播放自动解除，播放段被过滤时编辑框仍展示该段并提示。播放空白区时，跟随模式显示无字幕；锁定模式保留编辑段。

播放行以整行浅黄色和播放符号标记，编辑段用边框标记；同一行可以同时显示两种状态。内部 cue ID、processingRange、timelineViewport 仍各自独立，自动跟随只协调展示，不把播放位置当作字幕主数据。

## 布局与风格

上方左侧为较大的媒体区域，右侧上部为波形／时间轴，下部为当前段编辑；原文与译文上下排列。下方为整宽、固定行高的虚拟字幕表格。三处分隔线调整左右比例、上方／列表比例、右侧波形／编辑比例。视频和波形可独立折叠，媒体元素不因折叠卸载。

编辑页采用独立中性色工作台，紧凑标题、统一控件和网格线。常用播放、导航、时间和文字操作常驻；翻译、词表、候选与复核按需打开。收听页保留已有视觉风格。借鉴 Aegisub 的工作区和信息密度，不引入完整 ASS 排版、多选批量处理或另一套保存模型。

布局偏好按新区域语义升级版本，旧折叠状态保留，纵向比例重新初始化。继续保留 SQLite、cue ID、revision、导出格式、草稿和撤销边界。
