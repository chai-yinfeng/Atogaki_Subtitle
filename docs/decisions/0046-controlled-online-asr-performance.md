# 0046：受控在线 ASR 性能与可修改草稿

日期：2026-10-05。状态：accepted（用户批准的实验合同；效果待验证）。

在 0045 的独立 online 边界内，先比较 WS／SS／CPP，不接入 Qwen、不运行 MT。优先低延迟的可修改原文，开发目标为有效显示 p50≤1s、p95≤2s；稳定输出另测。由同源 small checkpoint 转换为未量化格式，SS 进行有限 torch MPS 适配，必要时向 base／tiny 下探，不为统一 runtime 移植主要 decoder 到 MLX。精度、硬件和原生上下文的剩余差异必须记录，受控对照不称为纯算法排名。

使用独立 32ms 因果供给和单个解码消费者；忙碌时合并已到达音频，不排队重复触发。VAD 主线只暂停静音解码并保留原 PCM／时钟，普通停顿不自动 finish/reset；尾部 decode、finish、reset、静音填零分别消融。EOF 不对完全无语音的 VAD 会话补造识别，保留尾部语音并记录未供给 ASR 的已检测静音。

显示、算法 commit、强制 flush 与窗口冻结保持真实语义。参考绑定原始音频与范围，Gemini 输出和 provider timestamps 仅作为待核验模型参考；语义核验、逐字听审和声学时间核验分开。缺失／错误锚点不从覆盖率分母消失。未完成参考、语义或长样本验收时不选生产胜者。

这取代仅按输入处理落后比较 backend 的做法。将所有 runtime 改成同一实现会扩大移植范围并改变原算法，本轮不采用；固定大模型则可能消耗后续翻译预算，本轮不采用。正式 offline 的模型、sidecar 和任务数据不改变；研究代码不成为桌面多 backend 框架。
