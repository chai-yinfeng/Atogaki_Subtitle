# 0043：分层处理管线、cue 对应与任务内 ASR runs

日期：2026-09-16

## 状态

已采纳，待分阶段实现。用户已确认第一阶段保持源／译 cue 对应，并允许 ASR 重跑作为同一任务下的独立 run 管理。

## 背景

当前 `TranscriptSegment` 同时承载 Whisper 输出、字幕分段和可编辑双语字幕。VAD／解码窗口由 Whisper 管理，细粒度时间信息没有独立领域表示；翻译按固定数量批次附加邻近上下文，缺少语义分组与依赖版本。模型替换、局部修复和实时结果难以共享明确的来源关系。

## 决策

1. 明确四种表示：供 ASR 使用的 acoustic chunks、保留最细可得时间信息的 word/token timeline、供阅读编辑的 subtitle cues、供翻译使用的 translation groups。VAD region、模型内部窗口、语义 group 和网络 batch 不视为同一对象。
2. 保持两段式 ASR → 可编辑原文 → 翻译。第一阶段每个源 cue 对应一个译文槽位，以稳定 cue ID 校验输出；group 可以包含多条 cue。缺失译文显式记录，不伪造内容。独立目标语言分段和多对多对齐暂不实施。
3. 一个任务保留一个当前编辑工作区，可拥有多个完整或局部 ASR run。run 冻结输入范围、provider／模型、参数及词表版本，保留结果和运行状态；重跑完成不自动替换工作区。采用候选仍执行范围、revision／快照校验和事务写入，并保护范围外编辑。
4. ASR 原始证据与工作区原文分开。自动规范化和人工修改需保留来源关系；不把旧 token 时间直接赋给不再对齐的新文字。缺失或插值时间明确标记，不从旧 cue 反向补造精确词级时间。
5. ASR suspicious 通过质量信号、评审判断和修复尝试表示。人工与自动评审均保留来源；分数用于审查优先级，不自动删除或覆盖字幕。
6. translation group 与请求 batch 分离，翻译输入记录目标 cue、实际上下文、术语与风格版本。写回校验相关版本及人工译文修改；原文变化可使依赖它的其他译文过期，但不自动覆盖人工译文。
7. SQLite 继续作为工作区与运行索引主数据；媒体和较大的不可变产物继续位于本地任务目录。此次不引入云端存储或全量事件溯源。local/cloud ASR 与 translation 独立组合，云端音频上传另行说明并由用户选择。
8. 实时会话将 candidate、stable、committed 与离线精修 revision 分开。E2E 翻译只作实验路线，不绕过正式资料的可编辑原文层。

## 替代方案与取舍

- 继续向 `TranscriptSegment` 增加字段改动较小，但仍混淆机器证据和人工工作区；采用独立 artifact／run，保留旧结构作为迁移期兼容视图。
- 每次重跑派生完整任务便于现有实现复用，但会复制任务入口并分散比较关系；新设计采用任务内 run。当前失败重试的新 UUID 行为在迁移完成前保持可用，不追溯合并已有任务。
- 先翻整组再独立切分译文可能改善语序和可读性，但需要多对多映射及更广泛 UI 重构；第一阶段保持 cue 对应，以完整分组上下文改善质量。
- 自动采用可疑片段修复结果会节省操作，但无法可靠区分真实重复、模型错误和用户意图；保留候选预览与显式采用。

## 与既有决策的关系

- 延续 [0025](0025-structured-translation-providers.md) 的稳定 ID、结构校验与批次恢复，后续补充 group 和版本依赖。
- 演进 [0040](0040-previewed-selected-range-retranscription.md)：实现任务内 runs 后，候选证据可以持久化，但采用资格必须重新校验；当前会话级预览继续有效，不能因持久化而绕过冲突检查。
- 保留现有学习来源快照、字幕样式和导出边界，不因 run 增加而重新生成所有 cue ID。
