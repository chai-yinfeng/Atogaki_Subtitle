# 0095 句型在原句中的解释与本地反馈

日期 2026-11-21。接续 [0094](0094-compile-japanese-grammar-from-formations.md)。

- **高亮。** 沿用原有谓语起点回溯，识别相邻的动词连用形与形容词性接尾辞，以及有形态证据的动词て形和后续补助谓语。由 Sudachi 的词性、原形、活用和原文坐标决定，跨时间断点仍按原分段匹配。
- **本句用法。** 收听结果先显示高亮范围和本句用法。部分已有规则提供能从形态确认的说明，例如「んだ」与「んです」的语体差别和「かも」缩略。其他条目引用命中卡的释义。已收藏例句打开卡片时保留原始高亮和该卡释义。词典只在有活用证据时提供对应的本句词形说明。
- **可回查反馈。** 漏报保存选区，误报保存被选中的条目和命中范围。复用学习区的字幕快照、UTF-16 坐标和回听入口，新增可空类型字段识别反馈。保存时再核对字幕，误报同时重新核对原有命中。重复提交复用来源例句。反馈可通过学习区搜索和删除，不进入 Anki，不在收听区作为已收藏知识高亮。

采用本机 SQLite 的学习来源记录，无需另建联网反馈服务或复制一套回听数据。反馈只表达用户对一次匹配的疑问，保存时不作自动语义裁决，也不改变规则。

同一期电台、同一 149 条字幕和 Sudachi Core 20261015，比较基线 `06f1c0e` 与本轮代码。此前留出的 40 条现在用于回归。其中 13 个已标注位置仍找到 8 个，高亮与标注一致的从 6 个增至 8 个，5 个漏报保留。全期仍有 67 条至少命中一个规则。跨行范围另有合成集成测试，其他节目仍待独立验证。私有复现文件位于忽略目录 `local-artifacts/evaluation/radio-grammar-spans-20261121/`，执行见同目录 `compare.py`。
