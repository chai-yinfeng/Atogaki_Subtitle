# 0048：显式批量翻译范围与上下文依赖替换

日期：2026-10-20

状态：已实施。

重译输出与旧译文完全相同时，`AFTER UPDATE ... WHEN OLD.translated_text IS NOT NEW.translated_text` 不会运行；旧上下文边残留，下一次普通 INSERT 因复合主键失败。写回现在在目标内容／人工译文快照校验成功后，在同一事务内删除该目标的旧边并写入新的去重上下文集合。不得仅忽略冲突，否则已不再使用的上下文仍会使译文过期。失败事务回滚，不影响此前成功批次，也不清空用户译文。无需迁移或修复既有数据库。

批量入口分为“补译缺失／过期段”和“全体翻译／重译”。前者仅选择缺译、原文过期或上下文依赖过期的段；后者即使存在待补译段也明确处理全体，并在执行前提示会覆盖人工译文。运行期间仍校验冻结输入，拒绝覆盖并发人工修改。自动翻译继续调用 pending 路线。

全体重译失败时，未处理段保留旧译文；补译仅处理实际缺失／过期段，不宣称可以恢复全体重译中尚未替换的有效旧译文。完整重译运行的独立逐段恢复 ledger 不在本次修复范围。

验证覆盖相同输出重复写回、重复依赖、上下文集合替换、冲突不删除依赖、被移除上下文不再触发过期，以及部分缺译时显式全体重译与无待补译时不发请求。
