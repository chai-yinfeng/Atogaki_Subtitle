# 0079：在线确认识别默认采用 Qwen3-ASR 1.7B 8bit

日期：2026-11-14。状态：accepted，用户在首批听审后明确确认收敛到此模型，并要求回归后调查 Voxt 实现。

## 决策

在线控制面板首次载入时优先选择 `qwen-1.7b-8bit`，模型目录将其标为在线默认。其他 Qwen 档位收进可选模型，既有 Whisper 分类、下载包、配置和人工资料保留。用户在当前面板显式选择的其他可用模型，刷新时继续保留；若默认包未安装，沿用既有选择可用模型的行为，不改变错误／权限处理。

本轮可用性依据为[候选筛选](../qwen-radio-candidate-screen-2026-11-13.md)：四档各两轮共 504 次计量请求，1.7B 8bit 无空输出／截断；10 段诊断听审中，用户判为 9 段可接受、1 段关键错误。它不是总体准确率、无损量化结论或正式在线语义验收。与未量化 1.7B 相比，本批计算和 MLX 分配器峰值更低，足以选定一个工作基线，停止日常扩大 ASR 模型矩阵。

模型仍使用目录中固定的 `mlx-community/Qwen3-ASR-1.7B-8bit` revision、逐文件大小和 SHA-256，由现有 Python／MLX worker 加载。切换默认不等于改为 native MLX、接入 Qwen 离线文件转录或完成新机 runtime 分发。

## 验证顺序与范围

先验证默认选择、实际开始参数、手动选择后刷新保留，以及模型分类；再用同一模型跑完整链路回归。冻结当前桌面默认的 SenseVoice 日语草稿、Silero VAD、Hy-MT2 1.8B Q4_K_M／8192 context／单 slot、现有分组与预译，场景和词表保持空。它与此前 Index-Translate 实验不同，不能把差异都归因为量化。

输入为 Vol.34 前 10 分钟和原 radio-06 三分钟，1 倍速使用生产共用 worker。没有人工修正原文、未来音频或参考译文送入主回放。只把实际返回／队列／错误当作结构与性能观测，不将定稿或正常退出等同于语义正确；采集、原生绘制与真实 App E2E 仍单独验收。保留失败、EOF 与清理记录。

回归完成后只读调查 Voxt 的发行版本和源码快照，重点核对 native MLX 如何组织音频分段／上下文、解码、流式展示、用户停止时定稿、错误恢复、模型管理及分发。其能交付语音输入 App 不等于已经解决连续电台翻译的问题。需要迁移其实现时，另行确认具体修改；不在调查中重写当前 pipeline。

执行结果见[13 分钟回归](../qwen8-online-regression-2026-11-14.md)与[Voxt 源码评审](../voxt-local-asr-review-2026-11-14.md)：运行和关联完整性通过，语义仍有问题；确认其默认使用相同包，可参考工程实现，不将本次决策扩大为 runtime 迁移。
