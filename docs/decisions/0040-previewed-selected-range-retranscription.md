# 0040：局部重新识别采用明确范围、隔离上下文和预览后替换

日期：2026-09-07

## 状态

已采纳。

## 背景

真实长节目中，Whisper 可能把某个短音节带入后续解码窗口并形成长时间重复。完整重跑成本高，也会危及已经完成的人工校对。自动检测重复、静默改写选区或直接覆盖字幕都可能误删节目中真实存在的重复表达。

## 决策

- 局部重新识别放在任务内字幕编辑工作面，由用户明确填写开始和结束时间。界面可以把当前可视窗口填入输入框，也可以在用户点击后扩展到全部相交字幕块，但不得静默改变边界。
- 如果选区边界切穿已有字幕块，后端拒绝识别；没有字幕的空白范围允许识别并新增候选。
- 识别复用该任务冻结的模型、语言、VAD、词表和其他参数，只把 Whisper 文字历史上限显式设为 `0`，避免污染文本继续反馈。它不是一套自动调参器。
- 新结果先以会话级候选并排展示，不写入 SQLite。确认时后端重新核对预览时受影响字幕的完整快照；发生过编辑则拒绝替换。
- 确认采用单个 SQLite 事务，只替换明确范围内的完整字幕块。新识别段不继承旧译文，范围外段和人工修改保持不变；会话内结构撤销可以恢复确认前快照。

## 后果

- 用户可以低成本修复局部循环或漏识别，同时清楚看到将被移除和加入的内容。
- 预览在 App 重启后失效，避免把临时候选变成第二套持久字幕主数据。
- 当前实现固定使用任务原参数与隔离上下文，不提供模型／参数 A/B；完整任务派生和跨结果对照仍按路线图后续实现。

## 2026-10-30：图形化选区

用户确认在复核工具内显示独立的波形与字幕时间轴，默认选中当前编辑段；可拖动两端手柄或在波形上重新拖选，手柄支持方向键 10 ms、Shift 100 ms 微调。时间输入、覆盖段数、原文摘要和切穿边界提示同步更新。视窗可缩放、翻页和横向滚动，不改变主编辑区视窗或字幕时间。显式对齐继续向外扩展到完整相交字幕块，不用波形峰值冒充语音边界。

工具复用现有时间轴绘制、波形读取适配层与唯一播放器。打开时暂停媒体；选区试听到结束停止，关闭或修改选区停止本次试听。试听期间主编辑段保持；本地／云端授权、预览后采用和后端完整块校验继续沿用原合同。工具卸载使待返回波形失效并释放绘制与事件资源。
