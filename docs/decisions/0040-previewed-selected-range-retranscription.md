# 0040：局部重新识别采用明确范围、隔离上下文和预览后替换

日期：2026-09-07

## 状态

已采纳。

## 背景

真实长节目中，Whisper 可能把某个短音节带入后续解码窗口并形成长时间重复。完整重跑成本高，也会危及已经完成的人工校对。自动检测重复、静默改写选区或直接覆盖字幕都可能误删节目中真实存在的重复表达。

## 决策

- 局部重新识别放在任务内字幕编辑工作面，由用户明确填写开始和结束时间。界面可以把当前可视窗口填入输入框，也可以在用户点击后扩展到全部相交字幕块，但不得静默改变边界。
- 如果选区边界切穿已有字幕块，后端拒绝识别；没有字幕的空白范围允许识别并新增候选。
- 识别复用该任务冻结的模型、语言、VAD、词表和其他参数，只把 Whisper 文字历史上限显式设为 `0`，避免污染文本继续反馈。它不是一套自动调参器。
- 新结果先以会话级候选并排展示，不写入 SQLite。确认时后端重新核对预览时受影响字幕的完整快照；发生过编辑则拒绝替换。
- 确认采用单个 SQLite 事务，只替换明确范围内的完整字幕块。新识别段不继承旧译文，范围外段和人工修改保持不变；会话内结构撤销可以恢复确认前快照。

## 后果

- 用户可以低成本修复局部循环或漏识别，同时清楚看到将被移除和加入的内容。
- 预览在 App 重启后失效，避免把临时候选变成第二套持久字幕主数据。
- 当前实现固定使用任务原参数与隔离上下文，不提供模型／参数 A/B；完整任务派生和跨结果对照仍按路线图后续实现。

## 2026-10-30：图形化选区

初版独立复核视窗在试用中暴露了操作对象混用；用户确认改为共享主时间轴。复核工具打开时挂载同一个波形面板（包含原有画布、缩放／强度滑杆、翻页、跟随、滚动／捏合及播放头控制），关闭时归还原挂载位置。没有第二套波形请求、缩放或播放位置；切入不重置视窗，返回保留调整后的视窗和播放头，暂停仍显示播放头。显式 mount／close／dispose 维护挂载位置与资源，不追加另一套播放器或手势控制。

默认识别选区仍取当前编辑段；字幕轨道拖选、两端手柄和时间输入只改处理范围，不改字幕。开始／结束可独立调整，输入不完整或起止倒置时保留各自输入并阻止识别，不自动改另一端。覆盖段数、原文摘要和切穿边界提示同步更新。“使用当前波形范围”和“使用播放头所在字幕段”读取共享时间轴。

显式向外对齐时，开始向左、结束向右找第一个字幕边界；已在边界保持，找不到使用媒体 0／总时长。空白区同样查找，不仅扩展相交字幕。例如字幕 10–15、20–25 秒，17–23 对齐成 15–25，17–18 对齐成 15–20 秒。不按波形峰值推断语音边界；后端仍校验完整字幕块并先预览后采用。

打开时暂停媒体；选区试听使用唯一播放器，到结束停止，关闭或修改选区停止本次试听。关闭不恢复旧播放位置；复核期间主编辑段和草稿保留。本地／云端授权及候选采用事务继续沿用原合同。
