# 0080：本地单路 Qwen＋DFlash 试用配置

日期：2026-11-16。状态：accepted for local trial；用户要求暂缓云端，固定相对可用的本地配置，编译安装到本机后亲自体验。不是稳定发行或两秒中文质量验收。

## 配置与范围

日语选择 `qwen-1.7b-8bit` 且 DFlash 加速包完整时，用一个 Python／MLX owning thread 提供预览和确认。主模型保持现有 1.7B 8bit／FP16，DFlash head 保持原始 BF16；约 1 秒刷新，完整音频块缓存与同边界 target／draft KV 复用，不启用固定文字前缀。VAD 延续 threshold 0.5、静音 0.5 秒、发声 0.25 秒、最长发声 12 秒和 0.2 秒 pre-roll。边界并不证明语义完整。

翻译继续使用已有 Retranslation：本机试用优先 Hy-MT2 1.8B Q4_K_M、8192 context、一个 slot，允许可回改预译；既有用户选择、词表／场景、确认原文历史和已到达后文合同保持。不是此前 EOF 后只翻译一次的隔离回放。ASR 与 MT 仍按任务交错，不默认开启 GPU overlap，不引入云端或新服务。目标仍为说话期间尽量两秒内看到可修订中文，实际体验由回放和用户试用分别记录。

其他语言或 Qwen 型号保持原双模型路径；未准备加速包时保留原有路径。配置了加速后若模型／runtime 不兼容或发生数值失败，明确报错，不在会话中悄悄切换另一识别器。新机 Python runtime 分发仍是单独交付。

## 执行与交付

复用现有有界 latest-preview 队列、8 个待确认 FIFO、事件 revision、StageAdmission 与共同停止预算。获得 GPU 执行机会后才从 final／preview 取最新需求，final 先于 preview。VAD 定稿可能短于已识别预览，此时重置音频缓存，不能让较晚音频影响较早定稿；同一完整输入已有结果时升级确认，不重复解码。迟到预览由既有事件合同拒绝，最终译文仍绑定全部确认源版本。

解码／音频缓存实现移入 `src/infrastructure/online_worker/`，实验目录只保留导入桥，共享测试和实现；DSpark 的研究能力不作为本机试用 profile。App 资源包含这些模块，不从研究目录导入源码。DFlash 两个必需文件使用模型目录固定 revision、大小和 SHA-256，现有下载／卸载机制管理；本机从已校验包导入，不把模型打入 App 或提交私人素材。

## 依据及未证明项

选择一秒是已有刷新对照中的 ASR 参照；0.5 秒增加排队和计算，1.5／2 秒会推迟首次原文。音频缓存保持固定前缀输出一致；文字前缀固定虽更快，但三段最终原文变化，未采用。自然 VAD、真实预译、停止和包装仍必须在本次接入后验证，不能用先前 final-only 结果代替；连续正确中文两秒、长时资源和新机器安装不由短裁片证明。
