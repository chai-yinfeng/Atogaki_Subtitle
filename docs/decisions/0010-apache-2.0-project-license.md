# 0010：Atogaki 项目采用 Apache License 2.0

日期：2026-08-06
状态：已采用

## 背景

Atogaki 已进入可生成 macOS App Bundle 和准备外部测试包的阶段，但仓库根目录没有项目许可证。公开仓库在没有许可证时仍受默认版权保护，外部使用者无法明确判断能否使用、修改、分发或贡献代码。

项目随 App 分发独立运行的 LGPL FFmpeg sidecar，并使用 MIT、ISC、BSD/FTL 等许可证的第三方组件。Atogaki 自身许可证需要与这些第三方材料明确区分。

## 决定

- Atogaki 自有源码、文档和构建配置采用 Apache License 2.0。
- 仓库根目录保存标准 `LICENSE` 文本，App Bundle 和后续安装包同时携带该文件。
- 第三方代码、sidecar、模型和其他材料继续遵循各自许可证；Apache-2.0 不覆盖或替换 `src-tauri/third-party` 中的许可证声明。
- 正式 Release 需要同时提供 Atogaki 项目许可证、完整第三方声明、LGPL 对应源码和构建清单。

## 后果

- 使用者可以使用、修改和商业分发 Atogaki，并须遵守 Apache-2.0 的许可证保留、修改声明和相关归属要求。
- Apache-2.0 提供明确的贡献者专利授权及专利诉讼终止条款，适合后续接受外部贡献。
- 已根据 Apache-2.0 获得的版本不能由后续许可证变更撤回；未来版本是否更改许可证仍取决于相关版本的完整著作权归属。
- 项目许可证落地不等于第三方合规完成；仍需为 Rust、Tauri 和前端依赖生成完整的第三方许可证清单。
