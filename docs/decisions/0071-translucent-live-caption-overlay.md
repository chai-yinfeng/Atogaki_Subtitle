# 0071：半透明全局字幕浮层与固定布局

日期：2026-11-03。状态：用户确认实施。延续0070的双框与独立提交，仅调整在线字幕窗的呈现和原生交互。

用户希望类似YouTube CC／全局歌词：屏幕边缘的半透明深灰底、清晰不透明的文字；原来的字幕区域会因长短句撑高而抖动，panel拖动／缩放也不顺畅。

在线字幕窗初始920×280，最小420×200；首次显示在控制面板所在屏幕可用区域底部居中、距底部24pt，保留用户本次会话手动移动／缩放的位置。允许原生边缘缩放，不添加自动吸附、位置持久化或透明度设置。窗口继续置顶／可跨Space及全屏辅助显示；隐藏不停止会话。手动点击“字幕窗”使实际panel成为key窗口，自动开始接收音频后的上屏仍不抢焦点。

外层WebView／原生panel透明，CSS卡片背景为rgba(35,35,38,.74)，文字保持alpha=1；不使用整窗降透明度或背景模糊。使用Tauri已有透明窗口能力，按其构建约定开启macOSPrivateApi及对应Cargo feature，不新增依赖版本；其他窗口不启用透明。原文／译文用固定的两个等分grid区域，内部文字滚动，锁定白色／活动蓝色继续使用既有事件逻辑。文本长度、换行及草稿转定稿不改变窗口或两区几何尺寸。

预留32px操作栏以防显示／隐藏引起位移，平时透明隐藏，鼠标进入或键盘聚焦时显示标题、状态和隐藏按钮。按钮命中不随opacity开关，避免鼠标刚进入、点击早于hover样式更新时吞掉第一次点击。标题栏不再向已隐藏的Tauri NSWindow发送拖动请求；在线专用NSPanel子类在标题栏区域直接消费鼠标按下并调用AppKit performWindowDragWithEvent。边缘缩放和按钮事件交还原生实现，不经JS轮询更新位置。命中区域需与CSS保留的标题栏同步，后续修改其尺寸时一起核对。

保留Wry已有的父视图／WebView宽高自动跟随，不复用Tao的原窗口delegate，否则其resize回调会将新panel误当作原NSWindow。使用标准Titled／Resizable＋FullSizeContentView，隐藏原生标题、透明标题栏并隐藏系统按钮，保留系统缩放命中区域；离线字幕panel保持原实现。尚未做帧率基准、跨屏DPI切换或全屏播放器矩阵，不能将一次交互检查写成所有卡顿已消除。实际安装与验证见路线图。
