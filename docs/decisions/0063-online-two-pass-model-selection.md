# 0063：Online two-pass 与模型范围收敛

日期：2026-11-02。状态：accepted（用户确认的方向；实现和性能待验证）。

## 决策

当前模型清单、执行顺序与状态统一见 [online计划](../online-asr-plan.md)。第一遍实时上屏，第二遍先对VAD／长度策略封口的完整音频段重新识别并定稿，翻译先消费定稿。VAD声学边界、ASR定稿与翻译语义分组分别处理。第二遍流式留到整段延迟不满足需要时再讨论。

新增SenseVoiceSmall、Qwen3-ASR 0.6B／1.7B；Mac先测MLX，必须另探索并在合适测试环境验证vLLM整段推理接口，不以MLX支持代替跨环境验证。日语第一遍尚未选定；Zipformer在缺少已验证日语checkpoint时只标中／英／韩各自模型场景。

Whisper主动清单收敛到small、medium和一个待选的large-v3 turbo／量化档；tiny／base与其他格式仅留历史或冒烟用途。本地MT仅保留正式名称为Hy-MT2 1.8B的候选，7B退出当前实验范围，云端可作为质量／延迟对照。Silero online维持锁定6.2.3；桌面GGML 6.2.0不在本次替换范围。

## 取代范围与权衡

本决策取代分支 [0045](0045-independent-online-experiments.md) 的模型探索顺序及 [0046](0046-controlled-online-asr-performance.md) 的WS／SS／CPP矩阵推进合同；独立online会话、不写正式工作区、记录真实证据的边界继续有效。原实验结果保留，不要求修完旧adapter或完成所有旧人工核验才开启新选型。

双模型增加内存、调度和草稿替换成本，第一遍必须证明有可读性收益。整段第二遍容易隔离质量与延迟，但增加等停顿的时间；快慢双流式的复杂度后置。云端转移算力成本，不能消除网络、等待和隐私边界。后续用实际日语和测试同学设备上的结果选择，不预设Qwen、SenseVoice或云端胜者。
