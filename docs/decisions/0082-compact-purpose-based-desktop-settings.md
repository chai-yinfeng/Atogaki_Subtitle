# 0082：按用途配置模型与共享主题的紧凑界面

日期：2026-11-16。状态：历史实施记录；外层布局和视觉规范由[0083](0083-neutral-shell-and-embedded-online.md)取代，按用途管理模型和配置保存合同继续有效。布局草图已讨论；借鉴 shadcn/ui 的紧凑控件与渐进展开，继续使用现有 TypeScript／Tauri 前端及主题，不引入 React 或另一套组件运行库。

## 配置与导航

工作台导航放左侧，媒体／新任务配置与最近任务并排；窄窗口重新排成单列。移除任务预设的界面和启动读取，不删除数据库里的既有预设或对应接口。保留正式设置、模型路径和后端配置，避免迁移用户数据。字幕编辑器工作区的独立布局保持。

设置使用左侧分区与一个内容滚动区，保存和关闭操作不随内容滚走。识别页集中转录模型、One Pass 加速包、Two Pass 草稿与 VAD；翻译页集中离线默认、在线本地默认、Hy-MT2 文件／已安装选择以及翻译模型下载管理；存储页保留目录。两处模型视图过滤同一个目录，复用同一个下载／取消／选择会话及互斥，不建立第二套模型管理。

翻译配置一次展开当前后端，切换仍使用现有独立草稿及凭据隔离；不自动测试或发送文本。离线默认仍经正式设置保存；在线默认和在线控制共用非敏感 WebView 偏好，只有显式修改在线默认时才写入，避免保存其他设置覆盖另一个窗口的选择。运行中的会话不接受跨窗口配置变更。

## 主题与组件约定

主窗口和在线控制共用 theme-tokens.css 中的月夜／来信语义颜色。在线控制复用已有图片主题校验和配色派生，响应其他窗口的主题变化；字幕悬浮窗继续保持独立的深色高对比底，不把主题图片铺到字幕上。图片主题编辑、背景和导出样式均沿用已有机制。

普通控件约 34px 高、6px 圆角，语言字段按短内容限制宽度，模型选择使用适中宽度，文件路径可伸展。减少大标题、重复解释与同时展开的后端卡片；错误、模型缺失和数据发送范围仍明确展示。键盘焦点与原生表单语义保留。

识别模式显式选择及语言范围见 0080 后继记录；换屏是 0081 的独立显示行为，不改变翻译历史。

## 验证边界

前端类型／构建、状态回归和生产 WebKit 的设置保存、后端草稿、凭据输入隔离、模型下载／文件选择、启动卸载及在线控制检查分别验证。两套主题和窄窗口检查不代表真实电台语义质量、长时内存或两秒目标通过。App 编译／安装与版本另记在路线图和本机安装记录。
