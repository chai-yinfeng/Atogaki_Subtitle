# 0018：任务词表同时保护机器翻译中的专有名词

日期：2026-08-11

## 背景

Whisper 提示词可让转写稳定写出作品名、人名等专有名词，但 DeepL 会把它们再次当作普通词义翻译。例如，作品名“盗作”不应在字幕中变为“剽窃”。现有词表的 `source => target` 语义是 ASR 的听写/规范写法修正，不适合作为中文译名表。

## 决定

- 每个任务已冻结的识别词表快照中，所有会进入 Whisper 提示词的词条都同时成为该任务的翻译保护词；修正规则两端的写法都会被保护。
- DeepL 请求以 XML 标签包住匹配词，并使用 `ignore_tags` 保留标签内容；响应回写前恢复原始文本。词条按长度优先匹配，避免短词截断长词。
- 不在本次改变中引入“专有名词中文译名”或任意替换规则。若以后确实需要固定译名，应新增独立字段、预览和冲突规则，而不是复用 ASR 修正字段。

## 后果

- 对已选择该词表的新翻译和重译，作品名、人名等会默认保留原文；无词表任务保持现有 DeepL 行为。
- 由于词表快照不可变，任务翻译结果可以复现，也不会被后来编辑全局词表悄然改变。
- 保护范围取决于用户在建任务时选择的核心词和内容包；对于用户手动改出的新译名，仍应由字幕编辑处理，直到独立译名功能有明确需求。
