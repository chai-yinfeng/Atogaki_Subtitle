# 0097 英日语收听学习和挖空复习

2026-11-26。收听区使用同一套点词、框选、词义候选、句型说明和收藏交互。日语保留 Sudachi、Tomoshi／JMdict 和现有语法库；英语复用本地 ECDICT 索引，支持原词、词典收录的异形、保守词形候选和明确选中的短语。英语基础句型独立于词典，首批覆盖进行式、完成式、there be、used to、going to 和 do 否定。英语框选及分析限当前字幕行。保留原选区与整句收藏以应对词典未安装或规则未命中。

词典收藏沿用本地事务和来源快照。相同词典、词条、所选义项及释义才能累积例句；ECDICT 的行号以数据版本作作用域。句型使用独立条目 ID。手动选词的新收藏按同一来源及范围去重，重存旧收藏中的同一个例句会复用原卡。两处收录了相同拼写或读音时，保存的义项仍可各自独立。收听里的已收藏高亮来自该条字幕真实保存的范围。

复习卡用收藏的字幕快照生成提示，揭示后提供释义和回听。普通 Anki TSV 保留全部来源。挖空 TSV 为每个能留下上下文的词或句型取第一条可用例句，使用保存的 UTF-16 范围，保留释义、字幕译文和来源。两种导出各有稳定的 Anki 笔记标识，同词不同义项可分别导入。整句收藏和语法反馈不生成挖空卡。学习区继续保留来源快照和全部例句。规划中的跨词典归并与复习间隔仍待验证。[Anki 文本导入](https://docs.ankiweb.net/importing/text-files.html)
