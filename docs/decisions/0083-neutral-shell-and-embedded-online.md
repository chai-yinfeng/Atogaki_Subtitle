# 0083：Neutral 主窗口与嵌入在线控制

日期：2026-11-16。状态：用户明确授权实施较大界面迭代；取代 0082 的外层布局／视觉，取代 0065 的独立在线控制窗口。模型配置及 0081 阅读退场不改变。

## 问题与确定方向

上一版同时在主样式声明侧栏 grid、在收听样式声明同一个 shell 为纵向 flex，播放器／正文宽高被错误挤压。继续追加高优先级覆盖无法提供明确的布局边界。用户确认按 shadcn 标准重做，而非保留旧的纸面／背景图设计。

采用 shadcn Neutral 的语义颜色、系统字体、统一表单、弱分隔与侧边 Sheet 交互，仍使用项目现有 TypeScript／Tauri 和原生 HTML 控件，不因视觉迭代引入 React。theme-tokens.css 管理颜色及旧局部模块所需别名；primitives.css 管理通用控件；app-shell.css 独占窗口布局，页面样式只定义内部布局。旧的重复 shell／全局主题覆盖已删除，其余局部模块样式保留并统一语义颜色。

## 窗口与页面

- 工作台主体是新建任务；最近任务默认隐藏在原生 dialog 侧边抽屉，保留原来的任务数据、搜索与操作。关闭支持显式 Escape 键处理、点击外侧、关闭按钮和焦点返回，进入任务时关闭抽屉。
- 常驻“刷新任务”只重复已有的两秒轮询，移除该按钮，读取／失败恢复仍由现有生命周期管理。
- 在线控制使用 online-view.ts 挂载到主窗口独立页面；根节点内查询，订阅／轮询／storage 监听可释放。切换页面不停止或重建会话，运行状态在导航中可见；Rust 仍拥有采集和模型进程。
- 移除原生 open_online_control 命令、窗口构造及 online-control 权限项，字幕参照主窗口定位。独立置顶字幕保留。online.html 只保留组件验证入口，不再从产品创建控制窗口。
- 收听页在主窗口剩余空间中分配节目列表、播放器和正文；每层 min-width／min-height 为零、滚动边界独立。右置／下置／隐藏全文和分隔拖动继续可用。编辑器保留独立全屏工作区及结构编辑、草稿保存等行为。

## 外观准备与回退

首次使用新 shell 时，原主题选择及完整图片配置写入 WebView 本地 atogaki.appearance.beforeShellV2；随后选择 neutral 并将图片配置设为未启用。只执行一次，后续手动选择不会被重置。旧图片／角色颜色／来源保留，外观设置可再次选择冷暖预设或启用图片配色，不删除素材、模型、数据库或字幕。存储不可用时使用 Neutral 默认，不阻断启动。

新的表单不把 range 输入当文本框；编辑器时间／速度短标签保持横排。自定义颜色仍通过语义 token 派生，不再让主题模块或页面重定义整个窗口布局。

## 验证边界

使用生产 WebKit 和合成 IPC／静音，检查任务页／抽屉默认关闭、搜索与列表间距、焦点恢复、收听三档窗口下各面板坐标、全文右置／下置、主窗口在线开始与离开／返回、运行状态及进入编辑器。既有脚本通过显式打开任务抽屉进入任务；等待初始化只观察挂载，不要求默认可见。
