## 用户试用后的色盘交互调整

三份重复色盘收敛为一份：先选择用途卡，再从共享颜色列表选择；每色保留稳定编号与明确的用途标记。同一个颜色可用于多个角色。指向或键盘聚焦仅更新局部预览，展示原色的当前／待选大色块、近似色名、明暗关系与派生后的文字／按钮示例；点击才写入原有角色配置，不新增配置格式。色号降为辅助信息，不依赖原生 title 悬浮提示。

保留旧配置及已不在新色盘中的显式选色。恢复自动只作用于当前用途，重新提取色盘仍保留各角色。继续不发布；原 v0.1.0 tag／DMG 不覆盖，改动仅更新本机 App，下一公开版本另行编号。
