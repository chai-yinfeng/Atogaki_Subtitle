# 0051：图片主题语义配色与 macOS 稳定发行

日期：2026-10-20

状态：实施；发行验证见路线图和发布说明。

用户确认当前离线工作流发布 macOS 稳定版，本轮不生成 Windows 安装包，不改变 Windows 共享核心维护边界。版本为 `v0.1.0`，仅 Apple Silicon；继续明确 ad-hoc 签名、未公证及质量门禁的限制。MLX 暂缓，桌面使用 whisper.cpp / llama.cpp 的 Metal 路线。

图片主题提供三个可独立选择的语义色角色：场景底色、阅读面色、按钮强调色。提取最多十二个具有代表性且有足够色差的颜色，每个角色可选自动或其中一个颜色。正文、次要文字、边框、悬停和选中状态从角色色派生，并约束对比度；错误和警告等语义色保持固定，不开放逐控件任意颜色配置。角色为空时兼容已有自动配色。“重新提取配色”更新旧图片色盘，保留已选角色、署名与模板。

保留月夜／来信模板中的材质与布局，颜色选择不生成笔触、拼贴或新材质。移除月猫专用本地文件、开关和主进程命令，统一走本机图片导入；不删除用户已有原图，不将任何官方作品素材随发行分发。

发行源码归档必须覆盖完整四个 sidecar，包括 llama.cpp。校验清单记录签名前原始二进制；不能以已签名安装版的摘要改写构建来源清单。构建输入使用独立文件，不能链接到会被签名或覆盖安装修改的 `/Applications` 副本。
