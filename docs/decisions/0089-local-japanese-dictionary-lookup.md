# 0089 在收听区本地查日语词和收藏原形

日期 2026-11-19。开发分支实现，真实节目试用待进行。

## 词法解析和释义

在 11 条手写日语样本上，用 SudachiPy 0.7.0／SudachiDict Core 20261015 与 fugashi 1.5.2／unidic-lite 1.0.8 对比词界和原形。两者都能在样本中处理「読んで」「読みました」「食べていなかった」和「買っちゃった」里的主要动词。Sudachi C 提供「東京大学」，A 同时提供「東京」「大学」。它把「ヨルシカ」留在同一范围并保留「聴く」写法。同音词「はし」和故意写错的「よんｄでた」仍需要候选或人工确认。该小样本用于选择交互所需的词形接口，不用于估算口语准确率。对照用例见[调研记录](../research/2026-11-18-subtitle-and-learning-options.md#词法样本对照2026-11-19)。

桌面端内置固定版本的 Sudachi Rust 解析器。用户在设置的「学习词典」主动下载对应 Core 词库，下载走既有 SHA-256 校验和原子安装；首次使用本地解压约 193 MiB 的派生文件，解析器在 App 进程内复用词库。原始 ZIP 中有许可证和上游归属声明。释义复用 Tomoshi（日中）和 JMdict（日英），两者独立可用。查词只读取当前字幕段和本机词库，无需 API Key。词库版本及语料归属见[许可审计](../third-party-license-audit.md)。

## 交互和收藏

点击日语字幕字形或在同一字幕段框选，解析器读取整段并以 UTF-16 范围返回相关词。界面展示实际命中范围、原形、读音和候选词条。Tomoshi 显示在 JMdict 前，同一来源可切换词条并选义。「読んで」中的连接助词可随动词高亮，查的词仍是「読む」。框选保留直接收藏原文与收藏整句入口。查询窗口沿用收听面板的跟随暂停机制，关闭后恢复原有跟随行为。

以来源、词条 ID、义项和义项文字确定复用的词卡。两套词典的中英义项分别确认，收藏后仍可按共享的 JMdict 词条 ID 查看对照来源。卡片保留当次选中的词形范围、字幕快照和原任务时间，词形、选义和来源在同一事务中写入。保存前重新检查候选和当前字幕；同一来源位置重复收藏不会增加例句。既有手工收藏按原路径读取，避免自动归并不同含义的旧条目。

首轮验收关注真实口语的候选能否覆盖想查的词、中文义项是否容易选、以及回听和继续播放是否顺手。匹配目前根据词界、写法、原形、读音与词典常用标记，假名同音词仍由用户选义。句型识别继续按独立的调研与验收推进。
