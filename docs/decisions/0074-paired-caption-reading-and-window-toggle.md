# 0074：原译文关联阅读与字幕窗开关

日期：2026-11-07。状态：用户确认实施。取代0070中两轨独立决定可见范围的规则，保留独立ASR／MT定稿与白蓝状态；不更改0072／0073的识别、翻译、等待或上下文。

## 关联显示范围

原来ASR以自己的最新音频位置清理内容，MT以较晚的输出位置清理，且所有草稿与上一完整定稿可绕过5秒规则，导致译文与屏上原文错位。

现在先选择可见MT组，再保留这些组的配套原文，最后追加最近约2秒的未译ASR尾部。MT仍以约5秒为软范围，但只保留最新活动组及范围内定稿，不无条件保留所有旧草稿或上一长定稿；拆分前缀提交后、尾组首条译文还没到时保留当前单元，避免短暂空白。旧原译文共同退出可见范围。

关联优先使用`source_revisions`的源段ID，再用音频范围；Qwen定稿原文保持白色，即使它尚未翻译。只有识别草稿为蓝色，不以翻译完成与否重定义ASR锁定。新原文通常略长于译文，但不承诺额外部分全部为蓝色。原文与译文仍各一框，不新增最近N组列表。

原文尾部按完整ASR段保留，不能伪造逐词时间或按字符比例切割。翻译积压而只展示最新尾部时，跳过的未译原文用灰色`…`标明，避免把不连续的发言直接拼成一句；此标记仅是展示元素，不是模型识别内容。长ASR段／MT组可超出软范围，现有固定窗框及内部滚动保持。

译文前缀改写仍节流约2秒，原文关联必须使用节流后实际显示的MT快照，而不是后台刚收到、尚未展示的新版本。当前配套原文在ASR缓存淘汰后仍保留快照；新开窗口时，后端提供最近最多64个ASR定稿及64个MT组最新revision，与256条近期事件合并。数量是内存保护，不是屏上历史数量。缺失原始ASR事件时可用MT事件的实际`source_text`恢复整组；MT final要求全Qwen定稿，未知草稿部分保持蓝色，不推断词级状态。

## 窗口开关

控制面板按钮改为显示／隐藏切换，文字与`aria-pressed`跟随实际可见状态。macOS查询及切换实际NSPanel的`isVisible`，不查询其背后始终隐藏的Tauri NSWindow。检查和切换在主线程执行；操作期间按钮防重入。锁定点击穿透时也能从控制面板开关，显示不抢焦点；未锁定手动显示可聚焦。浮层自身“隐藏”与控制面板状态一致，隐藏不停止会话。用户手动开关优先于待执行的自动上屏意图。
