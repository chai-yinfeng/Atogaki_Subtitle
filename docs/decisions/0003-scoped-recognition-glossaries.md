# 0003：按任务范围生成识别词表提示

日期：2026-08-04  
状态：已采用

## 背景

Whisper 的初始 prompt 长度有限。把人物、全部专辑和全部歌曲同时发送，会稀释最重要的人名提示，并使不同任务难以复现。识别后的确定性修正规则不占 prompt 预算，不应为了精简提示而被删除。

## 决策

SQLite 中的识别词条分为三种范围：

- `core`：每次选择该词表时都进入 Whisper prompt，优先用于人物、团体和稳定专名。
- `content`：归属一个内容包，只有新建任务显式选择该包时才进入 prompt 并参与该任务的识别后修正。
- `correction_only`：必须具有“误识别/读音 → 规范写法”，只参与 ASR 后修正，不进入 prompt。

核心和内容包词条都可以同时具有规范写法。任务提交前由应用服务解析所选范围，界面展示最终 prompt；提交后将解析结果保存为 `recognition-glossary.txt`，将实际 prompt 保存为 `whisper-prompt.txt`。处理核心继续读取任务快照，不依赖桌面 SQLite 的分类结构。

## 影响

- 人名可以获得稳定的 prompt 优先级，作品名按节目范围选择。
- 已完成任务不受后续词表分类修改影响。
- 对内容包的选择属于任务输入；未选择的内容包既不提示也不修正。
- 未来可以在不改变运行核心的前提下增加临时任务提示、优先级和 token 预算。
