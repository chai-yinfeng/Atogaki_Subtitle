# 0047：整体主题与未采用候选清理

日期：2026-10-19

状态：已实施；用户明确要求首批月夜／来信和未采用候选清理。

## 决策

主题内部按场景、阅读表面、控件与语义颜色分层；用户选择配好的整体主题，不提供背景与文字皮肤任意组合。用本机 localStorage 保存主题，未知值回到月夜；主题不改变布局、时间轴手势或导出样式。首版原创 SVG 随前端打包；2026-10-19 根据用户反馈改为生成的绘画／文具位图与纸张肌理，资产和提示词见 `../theme-material-assets.md`，不复制官方作品素材。前景区分半透明外围与稳定阅读面，不对整个工作区使用毛玻璃。

高级编辑以时间轴与当前字幕为主；待复核和识别修复是折叠辅助区。已确认问题缩为摘要，可展开修改判断，定位仍可用；后续反馈调整为误报／已解决默认隐藏，由“显示已处理”找回，审查决定保留以免下次读取重新弹出。

识别候选通过不可变运行摘要识别，名字展示范围、provider、模型简称、生成时间和短 ID。显式清理只释放未采用候选的产物，保留运行摘要、释放标记和检查点指针。原始识别不可清理；采用历史在字幕事务内写入 SQLite ledger，避免来源变更或 adopted.json 写入失败导致误删。迁移从现存 provenance 和 adopted repair records 回填。

清理、比较与采用共用 artifact 互斥锁；清理还持有识别锁，拒绝排队／运行中的任务。先原子提交释放标记，再删除允许目录内的产物；失败可幂等重试，已释放候选不能采用。检查点按内容共享，检查其他未释放引用后才释放。路径限制在该任务的直接子目录，递归删除不跟随符号链接。

## 取舍

任意主题混搭需要更多可读性组合验证，首批不开放。仅删除数据库记录会丢失审计线索，整目录删除会误伤采用证据；因此保留少量元数据并显示“已清理”。采用过但后来被替换的候选也继续保留，未来如要允许深度清理需另设来源归档策略。

翻译页只保留本地模型选择，模型路径、下载与卸载统一在模型与存储；云端各卡片继续使用独立配置与凭据边界。

## 字幕块增删补充（2026-10-19）

高级编辑允许在媒体范围内的空白插入有原文的新块，或显式删除所选块；不自动移动相邻块。请求携带完整预期字幕快照，在事务内核对，拒绝过时请求。复用会话内结构撤销，保留稳定 ID；未删除块的学习来源外键在重建后恢复，删除块的来源文本／时间快照仍保留。2026-10-20 修正失效范围：插入不改变已有翻译的冻结输入，删除仅使记录中引用被删块的机器译文过期；保留无关块和人工译文。旧的全片失效实现属于缺陷。新块范围由服务端 WAV 时长和数据库非重叠校验共同约束。
