# 0072：日语短块草稿与跨段重译定稿

日期：2026-11-04。状态：用户确认推进，首版启发式已实现；真实节目质量尚未通过验收。日语MT部分取代0070的默认提交条件，其他语言及双框阅读合同保持。

## 结构与边界

日语仍由SenseVoice滚动草稿、Qwen3-ASR定稿；Qwen完成即锁定原文。MT维护独立的待提交源文块，跨越短VAD停顿；短块译文保持蓝色，后续原文到达后整体重译，最终结果按明确source revisions替换同一块草稿。白色内容不再修改，不用译文字符串前缀拼接不同版本。

句末判断改为保守的表面启发式：完整ASR段末有标点、可见谓语结尾、累积至少8字符、后面连续已有至少8字符Qwen定稿原文，且后文不是若干常见的否定／补充连接形式。助词、犹豫语或「的な」等片段继续留在同一个Source Text内。只按完整ASR段拆分，不伪造词级时间。该规则不是语法分析器或语义完整性证明；普通体、引语、接话、自我修正仍会漏判或误判。

日语默认短停顿容忍从1.2秒改为3秒；连续Qwen定稿前缀的兜底等待从4秒改为8秒，仍从收到最早Qwen结果的音频时钟计，不是E2E上限。20秒／400字符、EOF与全组Qwen定稿依赖保持。长停顿／超时／长度上限是强制提交原因，不能视为完整句。它们是首版试用值，不是已优化阈值。其他语言仍使用1.2秒／4秒。

句末参考及已封口块的跨组后文仅取连续Qwen定稿源文，遇到草稿即停止，不跳过草稿读取更晚的定稿。后文最多500字符，只作参考、不计入本次翻译覆盖；已提交原文／译文仍各保留1000字符参考。历史译文可能传播错误，本轮消融没有证明删除它就能统一改善，暂不改变背景prompt。

显示的3–5秒软阅读范围独立于MT语义块；完整块可超过阅读范围。ASR／MT仍各一框混合锁定前文与蓝色尾部。新增“距首段结束”的等待指标，与“距末段结束”并列，避免较长MT块掩盖前半段实际等待。

## 依据与取舍

[NICT 2025技术报告](https://www.nict.go.jp/publication/shuppan/kihou-journal/houkoku71-1r_HTML/2025O-03-02.pdf) §2.2–2.3描述短chunk和整句两种翻译，并在边界匹配时用整句结果替换短块结果。其分割和上下文能力包含专门训练，不能将现成Hy-MT2视为等价实现。我们借鉴结构，允许替换的短块始终保持蓝色。

未采用：只增加固定等待而保持短片段分别翻译；让白色译文继续回改；每次增量额外调用一个LLM判断语义结束；首版引入需要训练的同传模型。选择先复用现有模型和事件合同，用固定ASR对照区分分段问题与MT能力问题。

## 验证与后续

新增短停顿合组、后置否定、后文必须Qwen定稿、跨组参考不重复翻译、超时不能锁定草稿、EOF覆盖和首段等待计时回归。固定ASR开发样本对照见[链路记录](../two-pass-smoke-validation.md#日语跨段重译首版2026-11-04)。当前结果减少定稿碎片，但增加等待，关键语气／否定／补全错误仍在，不能宣称质量改善或同传方案成熟。

下一步优先检查完整语义块MT质量与人工阅读体验；若完整原文仍误译，比较翻译模型／prompt／领域参考。若质量可以而等待过长，再改分割判断及调度。轻量后端只完成[调研](../local-translation-backends.md)，未下载或替换。
