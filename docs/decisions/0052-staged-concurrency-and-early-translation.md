# 0052：按阶段限流与稳定前缀提前翻译

日期：2026-10-20

状态：accepted，分阶段实现

用户确认 Whisper 默认同时执行两个任务，DeepSeek 文本翻译允许多请求并发，并与本地识别重叠。任务协调器与计算资源名额分开；ASR 阶段限额默认 2，所有桌面工作区和自动翻译共享 4 个云端请求名额。DeepSeek 每次执行最多同时派发 4 个独立语义 group，继续沿用不可变 provider 快照、逐组事务、上下文及人工编辑保护。首次失败停止派发后续 group，等待已派发 group 落盘；暂停则取消未提交请求并等待协调器收尾，再允许继续。

本地 Hy-MT2 每个请求独占 ASR 的全部资源名额，避免和两个 Whisper 同时挤占设备；本地提前翻译暂不开启。不同任务的 ASR 可以并行，单任务内部 acoustic chunks 保持有序、逐块原子提交。

下一阶段接入同任务稳定前缀的提前云端翻译：检查点为唯一原文来源，最新边界及翻译后文上下文保留缓冲；提前译文写入任务私有、带配置／输入身份与校验的持久 artifact。完整 ASR 发布后核对源文、上下文和人工 revision，再导入匹配结果，剩余分组沿用正常翻译。ASR 失败不丢译文，翻译失败不终止 ASR，也不提前开放编辑／成品导出；暂停与继续仍是用户控制。

不采用总进度百分比作为稳定条件：同样百分比对应的上下文长度随媒体时长改变。也不把部分原文直接写入人工工作区，以免完整发布覆盖临时 cue ID 或用户编辑。不通过无限增加任务 worker 实现所有阶段无上限并发。
