# 0068：桌面在线控制、字幕窗与更大的翻译上下文

日期：2026-11-02。状态：用户授权实施；已覆盖本机Atogaki供人工体验，尚未公开发行／合入main。

## 本次交付

沿[0067](0067-online-session-owner-and-system-audio.md)的会话底座，主窗口新增“在线字幕”入口，打开独立控制面板。按语言选择已验证的本地草稿：日语SenseVoiceSmall，中／英／韩对应Zipformer；Qwen3-ASR可选0.6B／1.7B，默认1.7B。控制面板提供本地Hy-MT2翻译及译文草稿开关、开始、停止并排空、打开字幕窗与最近定稿。

原文按segment展示草稿／模型定稿，译文按独立group展示；不把最新原文段误当作当前翻译组的一一对应输入。草稿用蓝色和状态文字标识，迟到译文快照注明正在追上原文。原文／译文各自的末尾至定稿时间单独展示，不能视为同一句的统一E2E延迟。Rust只保留最近256个带sessionId／sequence的事件作窗口恢复；旧会话结果不能覆盖新会话，监听与快照交错也不回退新版本。

字幕窗复用既有NSPanel置顶／全屏辅助窗口机制，但持有独立panel与在线状态，不复用离线播放浮窗的内容或控制。允许拖动／调整大小；隐藏只隐藏字幕，会话需在控制面板显式停止。窗口第一次点击可直接生效，避免非激活浮窗的第一下点击被吞。字幕面板按当前系统音频权限就绪后自动出现，避免在权限提示前抢先盖住提示。

## 用户反馈后的翻译组

后续澄清：用户需要扩大的是显示保留范围。本节扩大处理组的策略已由[0069](0069-online-settled-caption-retention.md)取代，以下保留当时实施与验证记录。

用户在桌面体验中指出翻译切换过快，接受比原来大约2–3倍的chunk，以保留更完整的日语语境。这里只扩大MT组，ASR的VAD／模型分段不改：停顿门槛1.2→3.0s，组上限20→45s、400→900字符；上限仍在声学段边界生效，可能超出当前ASR段长度。译文草稿仍按原间隔更新，不等待收口；最终提交更晚是有意的权衡。参数放大不等于每个实际组长度严格翻倍，更不保证长停顿就是语义完成。

为容纳更大的当前组与前组参考，在线Hy-MT2使用既有受管llama-server、单slot／8192上下文。离线provider原先的默认slot行为不变。服务在取得本地设备时段之后启动；鉴权只经后端环境传给worker，不送到WebView或写入配置。结束／失败／加载取消均关闭该服务，用户不需手动运行服务器。当前在线翻译仅本地Hy-MT2，不隐式启用云端或复用离线云端凭据发请求。

## 本机准备和安装

首个本机候选由`scripts/prepare-online-local.py`导入已有固定版本Python3.11、锁定环境依赖和模型，复制到App数据目录的runtimes/online与models/online。HF缓存链接被解引用，不依赖研究目录继续存在；manifest只用于本机已安装模型选择。它不是公开模型下载器或自动依赖安装产品。worker以-B运行，避免在签名后的App资源内生成pycache。

曾用独立标识验证空配置启动、模型就绪、真实系统音频和窗口行为；用户随后明确要求直接覆盖本地App。最终使用正常complete配置构建／签名，安装到`/Applications/Atogaki.app`，标识仍为`com.chai-yinfeng.atogaki`，使用既有正式数据目录。独立测试包已移出Applications，旧App留在忽略目录`local-artifacts/online/session-20261102/app-backups/Atogaki-before-online.app`供回退；没有删除研究环境或正式数据。正式安装脚本同步构建并检查audio-tap helper，offline最低系统要求仍为12.0。
