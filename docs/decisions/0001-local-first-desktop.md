# 0001：桌面、本地优先，而非先建设 Web SaaS

- 状态：已接受
- 日期：2026-08-03

## 背景

产品首先服务个人收听日语电台和观看视频。媒体文件较大，识别模型与系统音频采集高度依赖本机资源；同时用户希望保留对媒体和翻译 API 密钥的控制。

## 决策

离线精修的第一版采用本地桌面应用。UI 将优先选择能复用 Rust 核心的 Tauri；若 macOS 系统音频采集需要更深的原生能力，再通过小型 Swift/ScreenCaptureKit 组件补充。

## 后果

- MVP 不需要账号、JWT、云端上传、对象存储或 Postgres 服务。
- 文件、任务和词表默认保存在本机；任务元数据目标为 SQLite。
- 现有 Rust CLI 处理链保留并演进为桌面应用调用的核心。
- 将来若出现同步或协作需求，云端服务作为额外同步层，而不是替换本地处理链。
