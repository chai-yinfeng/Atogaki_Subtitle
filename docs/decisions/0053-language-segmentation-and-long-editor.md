# 0053：语言默认切分与长任务编辑开销

日期：2026-10-20

状态：accepted（既有用户授权的英文切分、渲染优化和本地音频回退）；翻译请求 batching／loopback 流式媒体随后获用户同意，见 0054。

英文新任务的 Whisper max_len 默认为 0，关闭字符长度强制包装，保留 provider 的原始时间范围；不在已有片段上自动合并，不按字符比例重造时间。日语与韩语保留 32，后者尚无充分样本，不随英文改动。CLI 未显式指定时沿用语言默认，--max-len 显式值优先。序列化选项、历史候选与继续任务保持冻结配置；旧英文任务需新建转录任务才使用新默认。取消长度包装不保证每段都是完整句子，VAD 停顿和模型自然边界仍然生效。

不采用仅把英文阈值调到任意更大字符数，亦不通过合并既有字幕规避用户要求。完整电影分句质量由用户之后重新转录验证；本轮只完成短片段及接口回归。

编辑器为不可变字幕快照构建带前缀最大结束时间的索引，保留原先重叠时选择第一条的行为；当前句查找与可视窗口查询不再每帧扫描全片。静态波形／字幕块缓存与播放头分开绘制。切换模式前先完成草稿 flush，再释放隐藏的整页字幕 DOM，不丢弃未提交编辑。时间修改与文字保存产生新快照，索引随之更新；拖动使用原始快照索引定位当前窗口、再读取 draft。

播放器增加显式任务 WAV 回退，保留位置、速率、音量、播放／暂停状态，并允许返回原媒体；task WAV 即使使用无扩展名的注册 URL，也必须挂载为 audio。切源释放旧媒体加载。原文件有 AAC 流并不能证明 WKWebView 已成功播放；仅视频无声不保证会触发 error 事件，因此不能只提供自动错误回退。

已发现自定义媒体协议在没有 Range 时整片 read_to_end 的内存风险。后续已获用户同意并实施仅绑定 127.0.0.1、白名单随机 token 的本机流式媒体服务，以及调用层短语义组打包；实现、验证与剩余边界见 [0054](0054-request-batching-and-loopback-media.md)。本记录对应第一批修改，不应单独用来宣称无声或吞吐已根治。
