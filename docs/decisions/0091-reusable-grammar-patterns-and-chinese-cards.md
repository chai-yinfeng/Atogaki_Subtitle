# 0091 日语接续规则复用与中文语法卡扩充

日期 2026-11-20。接续 [0090](0090-local-japanese-grammar-and-catalog.md)。

## 分词和接续匹配

Sudachi A 粒度提供一条有序的形态分析结果。适配层保留原文 UTF-16 范围、原形、主词性、细分词性、活用形、词典外标记和标点。词典查词仍可以使用 A／C 两种粒度。句型匹配引用 Atogaki 中已有的语法条目 ID，复用以下接续和词尾：

- 动词て形由动词连用形和真正的接续助词「て／で」组成。位置或手段的格助词「で」不满足这个条件。有关句型共用前缀，分别描述后面的成分，例如「もらう」「ほしい」「から」。词性中的「非自立可能」可收窄候选，还需结合接续、词形和上下文。
- 「ようにする／ようになる」共用前置接续，「ことにする／ことになる」同理。采用相同的助动词延伸来保留时态和礼貌体，使用统一的否定结尾识别「ない」及「ませ＋ん」。
- 只在明确列出的包含关系中，完整句型排除被它吸收的通用接续。许可「～てもいい」会排除同一范围内的让步候选「～ても」。其他实质上独立的嵌套命中仍可并列。口语缩略需要可复用的变体证据；分词或语义证据不足时可以留空。

原有匹配已经使用词性和活用。本轮将重复接续提到共享模板，新增 13 个可匹配条目，合计 37 个。适配使用 Sudachi 已有词性字段。匹配仍针对有局部接续证据的教学语法，跨分句关系、指代和省略需要额外证据。待积累代表性的人工标注样本后，比较依存分析或受限候选排序对这些漏项的收益，再决定是否接入。

## 内容和验证

按已有 ID 新增 72 张中文卡，包含接续、含义、用法、日文例句、中译和关联条目。优先补 N5 基础助词，以及授受、条件、推断等跨等级的常见句型。当前 526 条中有 96 条提供中文，另有 3 个中文基础概念。其余 430 条沿用 OpenJLPT 原资料。后续按来源约束起草和审校，保留原始目录、条目 ID 与数据署名。

真实 Sudachi Core 回归用手写正反例逐条验证已支持的 37 个条目，包括接续「で」、礼貌否定、授受方向、时间「てから」与地点起点「から」及覆盖冲突。真实节目的覆盖率待独立标注验证。评估同时记录条目 ID 和原文范围，区分漏报、误报、分词或 ASR 造成的失败，以及解析正确但解释难懂的情况。新增模板前比较它对一组正反例的作用；孤立个例先归类和记录。
