日期：2026-11-17。状态：按用户已确认的“设置中导入并命名，任务中选择”方向实施。

## 配置与资产

复用现有 SQLite settings 存储 recognition.registered_models，不新增数据库 schema 或模型服务。每项保存稳定 UUID、名称、类型和规范化绝对路径；应用内变更由同一互斥锁串行化。只注册路径，不复制或搬动大模型；“移除配置”不删除文件、任务或冻结识别结果。若被移除项也是旧全局 Whisper／VAD 默认，清除对应旧引用；其他仍有效的注册项可以作为未配置默认时的选择。

设置中提供 Whisper、Silero GGML VAD 文件及完整 Qwen3-ASR 目录的原生选择和命名。服务端检查类型、绝对路径、非空文件，Qwen 检查模型配置、processor、tokenizer 和权重存在；这是格式与存在性检查，不是模型质量认证，也没有受管下载的官方 SHA-256 证明。缺失或不完整时禁用任务选择。名称可以修改，ID 与路径不随改名变化。

设置不再显示旧 Whisper／VAD 裸路径输入；内部字段仍承接既有保存和任务兼容合同。受管下载和自定义注册共同进入离线基础识别列表，VAD 在高级选项按名称选择并记住偏好。提交时再次解析 ID 和校验文件，实际路径与配置仍冻结在任务内；删除名称不能把既有任务改为另一个模型。

## Qwen 用途与加速

自定义 Qwen 使用既有 MLX provider，离线仍要求 ForcedAligner 和独立对齐依赖；Qwen-only 注册也可满足首次配置，不强迫另装 Whisper。在线 Two Pass 确认识别共用注册列表，不把文件路径再次暴露给任务输入。One Pass 仍只接受已验证的受管 Qwen 1.7B 8-bit 与匹配 DFlash，不因名字相似为任意自定义包开启投机解码。
