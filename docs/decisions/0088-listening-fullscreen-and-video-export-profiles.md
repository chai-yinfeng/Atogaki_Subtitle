# 0088：收听全屏字幕与按用途导出视频

- 日期：2026-11-18
- 状态：采用，随开发版验证

用户确认优先完成全屏观看和导出。收听视频从任务已有字幕建立原生双语和仅译文轨道，由媒体时钟同步。视频全屏默认双语，可通过播放器字幕菜单切换；退出全屏继续使用原有外置阅读区。轨道随收听媒体销毁，独立音频和编辑器使用现有播放行为。原生轨道复用 WebKit 的全屏和时间轴能力，避免为进入全屏复制一个播放器或生成烧录文件。

导出入口提供三种用途。独立 SRT／ASS 继续和原片一起播放；需要单文件时可封装 MKV，将主视频和音轨复制，增加可开关的 ASS 轨。分享成片时，MP4 画质优先使用 Apple Silicon VideoToolbox H.264 的质量参数 80，取消从源码率推导的目标和峰值限制。后期可输出 MOV／ProRes 422 HQ（10-bit，PCM 音频），从中间文件再做交付压缩。新硬字幕档仅支持 SDR；遇到识别为 PQ／HLG 的片源提供软字幕或独立字幕。指定画质优先或 ProRes 后，编码器不满足要求时报告失败。旧的三档码率选项和回退继续按 [0042](0042-explicit-video-export-quality.md) 运行。

SRT／ASS 使用原有导出入口。三个视频模式复用既有字幕快照、独立任务记录、保存路径与覆盖确认、FFmpeg 进度、取消及临时输出。画质优先和 ProRes 不使用源码率估算大小，显示用途和文件大小取舍。质量参数 80 是初始预设；在真实高运动、暗部和颗粒片源上比较后，可根据画质、体积和速度修订这一参数。
