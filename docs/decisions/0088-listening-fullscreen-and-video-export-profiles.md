# 0088：收听全屏字幕与按用途导出视频

- 日期：2026-11-18
- 状态：采用，随开发版验证

用户确认优先完成全屏观看和导出。收听视频从任务已有字幕建立原生双语和仅译文轨道，由媒体时钟同步。视频全屏默认双语，可通过播放器字幕菜单切换；退出全屏继续使用原有外置阅读区。轨道随收听媒体销毁，独立音频和编辑器使用现有播放行为。原生轨道复用 WebKit 的全屏和时间轴能力，避免为进入全屏复制一个播放器或生成烧录文件。

导出工作区设两个入口。独立导出首先提供 SRT／ASS，单独生成字幕文件，原视频无需处理。需要把音画与可开关字幕放在一个文件里时，同一区域提供次级操作「封装 MKV 软字幕」；此操作复制主视频和现有音轨，并增加一条 ASS 轨。两个操作都避免重编码视频，界面明确写出文件形式。

烧录导出将字幕写入画面。「直接导出」可以用 Apple Silicon VideoToolbox H.264 的画质优先 MP4，质量初值为 80，取消从源码率推导的目标和峰值上限；也可沿用 [0042](0042-explicit-video-export-quality.md) 的三档目标码率和回退。「后期压制用中间文件」输出 MOV／ProRes 422 HQ（10-bit，PCM 音频），生成之后可用剪辑或转码工具另做压制。新烧录档用于 SDR；检出 PQ／HLG 时界面提示改用独立字幕或 MKV。指定画质优先或 ProRes 后，编码器不满足要求时报错。

字幕文件使用原有导出入口。软字幕封装与烧录复用既有字幕快照、任务记录、保存路径与覆盖确认、FFmpeg 进度、取消及临时输出。画质优先和 ProRes 显示大小取舍；实际高运动、暗部和颗粒画面仍待实测。详见[桌面测试](../desktop-testing.md#收听全屏与视频导出2026-11-18)。
