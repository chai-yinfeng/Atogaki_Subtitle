# 0050：本机图片导入、配色生成与外部来源链接

日期：2026-10-20

状态：实施并验收。

## 范围

用户明确请求本地图片导入与自动配色，沿用整体主题模板而不建设任意皮肤混搭或主题市场。当前保留一份最近导入的图片主题配置，可切回内置主题并再次启用。原有月猫个人素材入口兼容。

现有前景材质实际只有低强度共享阅读纸纹、来信细线与叠纸阴影；绘画笔触主要来自背景位图，尚未实现独立笔触前景或完整拼贴模板。自动配色不会生成这些艺术材质，也不宣称能自动复现作品风格。

## 数据与生成

用户通过原生文件面板或完整本机路径选择 PNG / JPEG / WebP（25 MB 上限）；主进程按文件签名识别类型，以 SHA-256 命名复制到数据目录 `themes/imported/`。使用唯一临时文件、同步落盘与原子提交；原文件不修改，同内容复用副本。SVG、网页和不支持格式拒绝。解码失败不会替换已保存的主题配置。

前端从主进程取得所选副本的二进制内容，经 Blob 在本机解码、缩小为 96×96 颜色样本；量化直方图提取主色，使用占比与饱和度选择强调色，忽略透明像素和极少量颜色离群值。生成稳定浅色阅读面、深色文字、边框及强调色；调整按钮颜色使其与按钮文字至少达到 4.5:1 对比度。正文和次要文字分别测试 7:1 与 4.5:1。彩色复杂背景不能仅依赖主色判断所有位置对比，标题等外围区域另加稳定遮罩。

模板决定月夜／来信现有材质关系，配色决定同组语义变量；用户可选择完整显示或铺满、界面遮罩强度及署名／来源。样式、提取色、文件标识与开关存于本机 WebView localStorage，图片副本持久化到应用数据目录，源文件移动后仍可用。恢复时仅允许注册该目录下合法哈希文件名的图片；缺失时回到内置外观并提示重新导入。字幕内容、时间轴、导出样式不受影响。

图片不会上传，不随 Git 或应用发行；未生成图片包再分发权限。当前没有自动清理之前导入的副本，避免隐式删除；相同图片去重，暂不提供多主题库。

## 链接

WebView 的 `target=_blank` 无法可靠打开网页；所有显式 HTTP / HTTPS 外链由主进程校验后交给系统浏览器。拒绝 file/javascript/自定义协议及含凭据 URL，不经过 shell 解析。主题来源与署名使用 DOM 文本节点，避免通过素材元信息注入 HTML。设置提供定位本机原图／导入副本入口。

## 验证

配色单元测试覆盖透明、极少量离群色、灰阶、高饱和及极端明暗，检查文字／按钮对比度；壳层测试覆盖导入去重、原始字节保留、非法文件、路径边界和外链协议。macOS 窗口与重启回归单列于路线图。Windows 共享代码编译路径保留，未宣称实机验收完成。
