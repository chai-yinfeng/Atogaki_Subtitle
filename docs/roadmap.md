## 统一字幕编辑器：当前状态

当前布局由 [0058](decisions/0058-compact-editor-and-playback-follow.md) 定义：左侧视频，右侧上方波形／时间轴、下方原文与译文上下排列，底部整宽虚拟字幕表格。默认跟随播放，单击或聚焦编辑后锁段，主跟随动作恢复。视频／波形可折叠，三处分隔线可调，布局跨任务记忆。

- **代码：** 0061 的全部结构 repository 收据已完成；后端 token 管理器、96 MiB 核算预算及淘汰／释放已实现并测量。共享应用会话已串行化结构提交／记录／撤销，候选服务共用同一会话，任务删除释放历史；IPC 与前端已切换至唯一 token 历史，旧数组恢复命令已移除；新隔离 release QA `c360cc9` 已通过删除、连续结构撤销、采用／撤销和重启失效的实际数据库核对；原文保存后的上下文过期显示缺口已完成轻量回填和单元／WebKit 修复，新原生复验前不更新本机安装包。旧 QA `2950a6d` 保留。
- **本机 App：** `/Applications/Atogaki.app` 为 `1020e05`，含时间保存和离页保护。安装与正常重启后 13 个任务／6,887 段、20 表摘要一致；安装验收结束时停在英语首句 9.847 秒、跟随开启。实际当前界面以用户操作为准。
- **公开发行：** macOS v0.1.2 资产未更新，本机候选不等于新的公开 Release。回退版本、签名及恢复点见[安装记录](local-editor-installation.md)。

## 下一步与验收门禁

1. **接入完整来源撤销。** 所有 repository 用例及有界后端 token 管理器已完成，预算基于 10,000 段实测确定为 96 MiB、每任务最多十条，详见 [0061](decisions/0061-transactional-structure-undo-metadata.md)。共享工作区／候选会话和提交／record／undo 门闩已接入，任务删除释放历史，提交后辅助标记失败保留成功结果与 token。IPC 与唯一前端 token 历史现已切换，按需 state 读取为 Cut／Join 提供 revision，预算／warning 已呈现。隔离 release QA c360cc9 已核对删除、Cut→Join→改时间→三次撤销、范围采用／撤销、重开 token 和重启失效；字幕、来源与三条依赖按修订映射恢复，原有过期语义保持。新增 [文字保存后上下文过期显示缺口](editor-context-stale-display-bug.md)：后台已传播，当前列表需重开才显示。轻量回填现已通过共享库 183／5 ignored、桌面 35／4 ignored、前端 281 及四组相关 WebKit；接着构建新隔离包原生复验，再考虑正式替换；正式旧包仍有原审计缺口。原生拖动、真实延迟／磁盘失败、IME、重启草稿冲突及平台门禁继续保留。
2. **继续性能验收。** 原生帧数据先验证窗口／进程归属与采集成本，再用同机同素材比较约 300／3,000／10,000 段的打开、滚动、输入、搜索、跳转与长素材后段定位。当前 WebKit wheel 帧间隔仍约 17–18 ms；Animation Hitches 的系统 surface 未可靠归属 QA，P95 保持未计算。固定循环 RSS 不能替代连续播放／滚动／输入、跨任务及工具卸载的长期趋势；保留首次可交互、长任务与内存门禁。
3. **按编辑用例收敛模块。** Cut／Join、插入提交／删除确认、唯一结构历史与撤销已进入独立协调模块，结构 IPC 集中在 editor-structure-backend，文字／波形沿用 editor-backend；结构事务及公共确认完成对应原生验证。公共确认视图已独立；0061 的共享服务与单一 UI 历史迁移现已完成代码／合成回归，新原生验收已覆盖主要结构事务；上下文状态回填已完成代码和合成回归，先原生复验，再收敛插入范围建议与导航协调。继续复用唯一 SubtitleDrafts、媒体和保存适配层，保留 mount／dispose、输入版本与请求代次。其余设置呈现、Rust 命令与大型 repository 分步抽取、逐次回归；不用模块搬移作为性能通过证据。
4. **补齐平台和文件流程。** 原生字幕覆盖、批量确认、烧录覆盖仍待验证；系统目录面板 Open 间歇禁用、菜单选值和原偶发锁定保留。真实 libass 初始预览、SRT 写入／定位、合成视频烧录完成及长任务取消已有局部证据。首次直接启动空白曾在同进程恢复，系统入口重开正常，根因仍未确定。Windows 选定候选独立实机检查，macOS 结果不外推。
5. **维护交付与保留边界。** 里程碑完成后提交／推送，按已授权流程决定下一次本机候选更新；正式数据不作破坏性测试。App 轮换保留上一版与稳定版，SQLite 快照相同则复用；模型、媒体、数据库、采用证据、人工评审、主题来源及未知文件不自动清理。路径／用途／版本／checksum 与清理记录见[保留清单](local-artifact-retention.md)。[Web／Postgres 报告](legacy-web-retirement-impact.md)已交付，移除实施待讨论。

用户已确认把《教父》短片段排查并入本目标：旧任务通过 App 删除，原媒体与隔离证据保留；不新增自动事后纠错。按 [0060](decisions/0060-overlap-alignment-before-acoustic-selection.md) 修复了重叠区双重排除，真实检查点重放恢复对白，新默认 58→59 段。人工听辨、其余失败点、完整长片及实际翻译质量仍待验收，见[短片段基线](godfather-short-baseline.md)。

[翻译消耗观测](translation-usage-observation.md)已进入本机 1020e05：记录本地复用、可选云端 prompt-cache token 与计划信息，保留旧缓存 checksum。尚未调整翻译分组／上下文，也未证明真实请求次数、旧任务命中率或费用改善；这些质量与消耗结论独立于编辑器工程回归。

## 产品与研究后续

原 P0–P5 的逐项合同与历史状态见[管线演进计划](pipeline-evolution.md)及[历史路线图](roadmap-history-2026-10-22.md#本轮处理管线与翻译质量)。下列保留待验证，不晋升为本轮新增功能：

- 固定真实短片段／完整长节目、少量人工参考和保留测试集；识别接缝、英文分段及人工听感继续验证，不从结构测试推导识别准确率。
- Hy-MT2／MLX／现有云端基线的人工盲评、完整任务峰值内存与 ASR 资源竞争；MLX 输出合同失败不降低标准。Windows 本地 runtime 与平台体验单独评估。
- 真实云端吞吐、限流／断网、Gemini 范围上传／删除与日英网络闭环、VAD 静音出字信号；服务／模型质量与 UI 工程回归分开。
- Windows 英语／韩语真实节目闭环、凭据、模型下载／代理、WebView2 媒体、字体与 libass、导出／烧录及悬浮字幕。悬浮字幕当前不稳定，不建议使用。
- 学习检索、多来源与文本 Anki 已有实现；长期收藏／回看使用验证及内建复习、复杂标签的产品优先级继续待讨论。多选、批量平移、频谱、逐帧、全局播放快捷键与复杂 ASS 不在当前编辑器改造验收内。
- 真实流式录音／系统音频采集、prefix 提交与会话后离线精修留在 CLI／research。跨设备同步、账号协作、云端托管、多租户、多轨和高级排版只在明确需求与独立决策后考虑。
