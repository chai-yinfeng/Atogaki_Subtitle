## 统一字幕编辑器：当前状态

当前布局由 [0058](decisions/0058-compact-editor-and-playback-follow.md) 定义：左侧视频，右侧上方波形／时间轴、下方原文与译文上下排列，底部整宽虚拟字幕表格。默认跟随播放，单击或聚焦编辑后锁段，主跟随动作恢复。视频／波形可折叠，三处分隔线可调，布局跨任务记忆。

- **代码：** 0061 的全部结构 repository 收据已完成；后端 token 管理器、96 MiB 核算预算及淘汰／释放已实现并测量。共享应用会话已串行化结构提交／记录／撤销，候选服务共用同一会话，任务删除释放历史；IPC 与前端已切换至唯一 token 历史，旧数组恢复命令已移除；新隔离 release QA `c360cc9` 已通过删除、连续结构撤销、采用／撤销和重启失效的实际数据库核对；原文保存后的上下文过期显示缺口已完成轻量回填，release QA `2a82da1` 已通过即时标记／清除及筛选保留编辑段的原生复验。当前 QA 已独立编译标识 `com.chai-yinfeng.atogaki.qa`，位于 `/tmp/atogaki-editor-token-qa/Atogaki QA.app`，已原位更新至 `778d936`；7849794 已用合成库验证编辑打开、插入／撤销；35181fb 再验证近期模块集成、循环、范围授权、历史候选重新对照、工具往返及恢复跟随，默认目录亦独立；本机已安装 28e2909（产品代码 778d936）供继续试用。旧 QA `2950a6d` 保留。
- **本机 App：** `/Applications/Atogaki.app` 已更新为 `28e2909`（产品代码 778d936），包含音频按需加载与恢复保护、词表选择竞态／修正弹窗修复。正式包 27 文件／签名和四 sidecar 已核对；安装前后 20 表一致，13 任务／6,887 段保留。只读打开英语视频，定位／播放后暂停于第 3 段并恢复跟随，供用户继续体验。恢复点内容相同故链接复用，App 仍只保留上一版与稳定版。用户此前已确认 e8d9a8d 的紧凑布局、上下原译文及跟随／锁段“目前正常”；用户随后确认首次播放／定位、重开恢复位置及词表修正“目前正常”，这组手动验收通过；性能及平台门禁单列。
- **公开发行：** macOS v0.1.2 资产未更新，本机候选不等于新的公开 Release。回退版本、签名及恢复点见[安装记录](local-editor-installation.md)。

## 下一步与验收门禁

1. **完成草稿与结构恢复的剩余验收。** [0061](decisions/0061-transactional-structure-undo-metadata.md) 的唯一后端 token 历史、96 MiB 预算、来源／翻译依赖恢复与共享会话串行提交已实现。隔离 QA 已验证删除、Cut／Join／时间连续撤销、候选采用／撤销、重开／重启历史边界；上下文过期显示已修复。真实 SQLite ABORT、独立 ENOSPC、正常退出草稿恢复及冲突确认、ABORT 后 SIGKILL／同库恢复均有证据，详见[窗口验收](editor-workspace-validation.md)。原生鼠标拖动仍受工具限制，立即终止／满卷组合及其他磁盘 IO 尚无证据；不把已验证的单路径当成全部恢复组合完成。正式数据继续仅供用户手动验收。
2. **继续性能验收。** 已补[三档生产 WebKit 对照](editor-version-comparison-2026-10-29.md)：当前 300／3,000／10,000 段均 14 行、682 个 DOM 元素，基线万段约 16 万元素；真实事件窗口的 rAF 间隔 P95 中位基线为 17／23／160 ms、当前均 17 ms。万段基线波动大、一次窗口延长至约 5.7 秒，不能外推稳定帧率或原生呈现。打开／搜索／保存为合成 IPC 观察值，不充当严格 TTI／SQLite 写入；两版普通保存均保留原行。Long Tasks API 不支持，指标不可用。旧协议的驱动等待／准备动画缺陷及探索数字已明确废止，方法与原始数据保留。

   原生三小时三档打开、后段定位及 616 秒／53 轮混合加 127 秒空闲已有证据；该负载未见逐轮持续增长，另一次更快 WebKit 负载的 RSS 抬升及未知保留对象仍未归因。音频按需加载已进入本机且用户确认正常，首次实际加载的大范围预读暂态仍需独立测量。

   原生键盘滚动和文件信号同步已验证。两版 3,000 段短按落入 trace，但当前版缺少宿主到显示 surface 的桥接，不能比较呈现 P95。[原生 Inspector 预检](editor-native-webkit-inspector-2026-10-29.md)另取得实际页面时间线和单次两秒 rAF 原始样本（回调间隔 P95 18 ms）；Rendering Frame 记录仍缺失，不能把回调样本当作完整渲染耗时或呈现改善。

   当前优先收尾实际使用与恢复／文件流程，不再以反复采集阻塞可用候选交付。严格首次可交互、长任务、首次加载暂态及同负载原生呈现改善继续标为未证明；后续有明确性能问题再安排有界专项。若恢复诊断，需先补时间标记／request ID 对应，并统一历史版诊断配置；当前窗口归属未建立前不扩大 Hitches 录制。方法、失败数据与局限见[性能记录](editor-performance-validation.md)。

3. **按实际编辑边界整理模块。** 主要编辑会话、唯一草稿／播放器、虚拟列表、时间轴、导航、处理工具和资源生命周期已逐步独立；Rust 26 条命令及编辑／发布／查询／翻译回填／ASR run 和审查 repository 已分批抽取，沿用原事务。[架构说明](architecture.md#字幕编辑前端的渐进边界)记录当前责任。近期按迟到返回审计修复词表预览／规则／任务快照以及修正弹窗的访问隔离；独立 QA 1f61307 已验证前一组，21a010e 原生复验修正弹窗时发现 HTML showModal 会隐藏 AX 控件，已复用现有具名弹窗边界；correction／selection／follow WebKit 与 9fc1efe 原生命名控件／正反 Tab／取消重开已过，20 表不变。剩余 main 协调仅按发现的实际边界处理，不为拆文件继续搬移非编辑产品区域；模块回归不能替代性能证明。
4. **补齐平台和文件流程。** 原生原文 SRT 单文件取消／确认覆盖已通过；译文 SRT／双语 SRT／ASS 三文件首次导出、内容一致和批量取消已通过，后继父窗口候选补过三文件确认覆盖与实际 SHA 一致，烧录覆盖仍待验证；系统目录面板 Open 间歇禁用在任务临时目录与工作区可写目录均复现，父窗口绑定未消除；用户已确认正式 App 切换可写目录后 Open 正常可点，隔离现象仍待归因，菜单选值和原偶发锁定保留。真实 libass 初始预览、SRT 写入／定位、合成视频烧录完成及长任务取消已有局部证据。首次直接启动空白曾在同进程恢复，系统入口重开正常，根因仍未确定。Windows 选定候选独立实机检查，macOS 结果不外推。
5. **维护交付与保留边界。** 里程碑完成后提交／推送，按已授权流程决定下一次本机候选更新；正式数据不作破坏性测试。App 轮换保留上一版与稳定版，SQLite 快照相同则复用；模型、媒体、数据库、采用证据、人工评审、主题来源及未知文件不自动清理。路径／用途／版本／checksum 与清理记录见[保留清单](local-artifact-retention.md)。[Web／Postgres 报告](legacy-web-retirement-impact.md)已交付，移除实施待讨论。

导出界面优先推荐 SRT／ASS 搭配原视频，明确烧录会重新编码、可能进一步损失画质；档位改称视频码率，并说明源码率缺失时使用分辨率估算，码率百分比不保证保真。现有编码器、默认档位、格式与后端合同不变；软字幕封装和编码策略调整另行讨论。349 项前端测试、类型检查／生产构建、两套 fmt 与 diff 检查通过；这组说明尚未安装到正式 App。

用户已确认把《教父》短片段排查并入本目标：旧任务通过 App 删除，原媒体与隔离证据保留；不新增自动事后纠错。按 [0060](decisions/0060-overlap-alignment-before-acoustic-selection.md) 修复了重叠区双重排除，真实检查点重放恢复对白，新默认 58→59 段。人工听辨、其余失败点、完整长片及实际翻译质量仍待验收，见[短片段基线](godfather-short-baseline.md)。

[翻译消耗观测](translation-usage-observation.md)已进入本机 1020e05：记录本地复用、可选云端 prompt-cache token 与计划信息，保留旧缓存 checksum。尚未调整翻译分组／上下文，也未证明真实请求次数、旧任务命中率或费用改善；这些质量与消耗结论独立于编辑器工程回归。

## 产品与研究后续

原 P0–P5 的逐项合同与历史状态见[管线演进计划](pipeline-evolution.md)及[历史路线图](roadmap-history-2026-10-22.md#本轮处理管线与翻译质量)。下列保留待验证，不晋升为本轮新增功能：

- 固定真实短片段／完整长节目、少量人工参考和保留测试集；识别接缝、英文分段及人工听感继续验证，不从结构测试推导识别准确率。
- Hy-MT2／MLX／现有云端基线的人工盲评、完整任务峰值内存与 ASR 资源竞争；MLX 输出合同失败不降低标准。Windows 本地 runtime 与平台体验单独评估。
- 真实云端吞吐、限流／断网、Gemini 范围上传／删除与日英网络闭环、VAD 静音出字信号；服务／模型质量与 UI 工程回归分开。
- Windows 英语／韩语真实节目闭环、凭据、模型下载／代理、WebView2 媒体、字体与 libass、导出／烧录及悬浮字幕。悬浮字幕当前不稳定，不建议使用。
- 学习检索、多来源与文本 Anki 已有实现；长期收藏／回看使用验证及内建复习、复杂标签的产品优先级继续待讨论。多选、批量平移、频谱、逐帧、全局播放快捷键与复杂 ASS 不在当前编辑器改造验收内。
- 真实流式录音／系统音频采集、prefix 提交与会话后离线精修留在 CLI／research。跨设备同步、账号协作、云端托管、多租户、多轨和高级排版只在明确需求与独立决策后考虑。
