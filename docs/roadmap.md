# 开发路线图

_最后更新：2026-08-04_

路线图按用户价值排序；完成一个阶段前，不提前将后续阶段变成产品默认路径。

## 0. 处理核心稳固（当前）

- [x] 本地转码、Whisper 转写、词表修正、DeepL 翻译、字幕导出与渲染。
- [x] 文件任务清单与阶段性状态。
- [x] 将应用层的识别配置从 CLI/Web 类型中解耦。
- [x] 使用 UUID 任务目录，并提供 UI 可消费的任务快照读取接口。
- [x] 本地持久化任务队列、单 worker 后台执行与可轮询快照。
- [x] 将处理核心提取为 Rust library；CLI 成为薄入口，供未来桌面 UI 复用。
- [x] SQLite 本地迁移、任务/字幕段快照同步和桌面任务列表索引。
- [ ] 为任务目录、选项转换、分段与导出添加离线可运行的测试。
- [ ] 明确本地配置、模型路径和密钥存储策略。

## 1. 桌面离线 MVP

- [x] 初始化 Tauri 桌面壳与前端工程，读取本地 SQLite 任务列表。
- [x] 选择本地媒体与 Whisper 模型，创建后台日语转写任务并展示持久化任务状态。
- [ ] 实现视频/音频播放器和与时间轴同步的双语字幕列表。
- [ ] 支持编辑字幕、保存、标记过期翻译、单段/全部重译。
- [ ] 词表的创建、选择和应用。
- [ ] 导出 SRT、ASS 和带字幕视频。

**验收：** 用户能独立完成“导入一段日语节目 → 获得并校对双语字幕 → 定位一句话 → 导出”的流程。

## 当前技术债清单

- 当前 Web API 和 Postgres schema 是早期探索，不应驱动桌面 MVP 的设计。
- 当前识别与翻译选项已可配置；UI 在 MVP 中只暴露日语到简中的默认组合。
- 当前字幕 JSON 已有稳定段 ID、来源编辑状态与翻译过期状态；细粒度编辑历史仍待实现。
- 应用中断时尚不能自动恢复正在排队或执行的任务；后续需增加“中断/重试”状态与恢复策略。
- 当前本地回归已覆盖 Rust 核心、SQLite、前端生产构建与 Tauri 编译；仍需建立持续集成基线。
