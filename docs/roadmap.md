## 下一步与验收门禁

1. **完成草稿与结构恢复的剩余验收。** [0061](decisions/0061-transactional-structure-undo-metadata.md) 的唯一后端 token 历史、96 MiB 预算、来源／翻译依赖恢复与共享会话串行提交已实现。隔离 QA 已验证删除、Cut／Join／时间连续撤销、候选采用／撤销、重开／重启历史边界；上下文过期显示已修复。真实 SQLite ABORT、独立 ENOSPC、正常退出草稿恢复及冲突确认、ABORT 后 SIGKILL／同库恢复均有证据，详见[窗口验收](editor-workspace-validation.md)。三条分隔线键盘调整、折叠／比例重启记忆和恢复默认已补原生证据；原生鼠标拖动仍受工具限制，立即终止／满卷组合及其他磁盘 IO 尚无证据；不把已验证的单路径当成全部恢复组合完成。正式数据继续仅供用户手动验收。
2. **继续性能验收。** 已补[三档生产 WebKit 对照](editor-version-comparison-2026-10-29.md)：当前 300／3,000／10,000 段均 14 行、682 个 DOM 元素，基线万段约 16 万元素；真实事件窗口的 rAF 间隔 P95 中位基线为 17／23／160 ms、当前均 17 ms。万段基线波动大、一次窗口延长至约 5.7 秒，不能外推稳定帧率或原生呈现。打开／搜索／保存为合成 IPC 观察值，不充当严格 TTI／SQLite 写入；两版普通保存均保留原行。Long Tasks API 不支持，指标不可用。旧协议的驱动等待／准备动画缺陷及探索数字已明确废止，方法与原始数据保留。

   原生三小时三档打开、后段定位及 616 秒／53 轮混合加 127 秒空闲已有证据；该负载未见逐轮持续增长，另一次更快 WebKit 负载的 RSS 抬升及未知保留对象仍未归因。音频按需加载已进入本机且用户确认正常，首次实际加载的大范围预读暂态仍需独立测量。

   原生键盘滚动和文件信号同步已验证。两版 3,000 段短按落入 trace，但当前版缺少宿主到显示 surface 的桥接，不能比较呈现 P95。[原生 Inspector 预检](editor-native-webkit-inspector-2026-10-29.md)另取得实际页面时间线和单次两秒 rAF 原始样本（回调间隔 P95 18 ms）；Rendering Frame 记录仍缺失，不能把回调样本当作完整渲染耗时或呈现改善。

   当前优先收尾实际使用与恢复／文件流程，不再以反复采集阻塞可用候选交付。严格首次可交互、长任务、首次加载暂态及同负载原生呈现改善继续标为未证明；后续有明确性能问题再安排有界专项。若恢复诊断，需先补时间标记／request ID 对应，并统一历史版诊断配置；当前窗口归属未建立前不扩大 Hitches 录制。方法、失败数据与局限见[性能记录](editor-performance-validation.md)。

3. **按实际编辑边界整理模块。** 主要编辑会话、唯一草稿／播放器、虚拟列表、时间轴、导航、处理工具和资源生命周期已逐步独立；Rust 26 条命令及编辑／发布／查询／翻译回填／ASR run 和审查 repository 已分批抽取，沿用原事务。[架构说明](architecture.md#字幕编辑前端的渐进边界)记录当前责任。近期按迟到返回审计修复词表预览／规则／任务快照以及修正弹窗的访问隔离；独立 QA 1f61307 已验证前一组，21a010e 原生复验修正弹窗时发现 HTML showModal 会隐藏 AX 控件，已复用现有具名弹窗边界；correction／selection／follow WebKit 与 9fc1efe 原生命名控件／正反 Tab／取消重开已过，20 表不变。剩余 main 协调仅按发现的实际边界处理，不为拆文件继续搬移非编辑产品区域；模块回归不能替代性能证明。
4. **补齐平台和文件流程。** 原生原文 SRT 单文件取消／确认覆盖已通过；译文 SRT／双语 SRT／ASS 三文件首次导出、内容一致和批量取消已通过，后继父窗口候选补过三文件确认覆盖与实际 SHA 一致，实际 FFmpeg＋SQLite 服务已补拒绝／确认覆盖、可解码、缺失／损坏 ASS 失败及排队取消后的旧文件与源视频保护回归；粘贴路径的原生烧录取消／确认覆盖及重复确认已通过；系统保存面板、运行中取消已有目标与崩溃窗口仍待验证；系统目录面板 Open 间歇禁用在任务临时目录与工作区可写目录均复现，父窗口绑定未消除；用户已确认正式 App 切换可写目录后 Open 正常可点，隔离现象仍待归因，菜单选值和原偶发锁定保留。真实 libass 初始预览、SRT 写入／定位、合成视频烧录完成及长任务取消已有局部证据。首次直接启动空白曾在同进程恢复，系统入口重开正常，根因仍未确定。Windows 选定候选独立实机检查，macOS 结果不外推。
5. **维护交付与保留边界。** 里程碑完成后提交／推送，按已授权流程决定下一次本机候选更新；正式数据不作破坏性测试。App 轮换保留上一版与稳定版，SQLite 快照相同则复用；模型、媒体、数据库、采用证据、人工评审、主题来源及未知文件不自动清理。路径／用途／版本／checksum 与清理记录见[保留清单](local-artifact-retention.md)。[Web／Postgres 报告](legacy-web-retirement-impact.md)已交付，移除实施待讨论。

导出界面优先推荐 SRT／ASS 搭配原视频，明确烧录会重新编码、可能进一步损失画质；档位改称视频码率，并说明源码率缺失时使用分辨率估算，码率百分比不保证保真。现有编码器、默认档位、格式与后端合同不变；软字幕封装和编码策略调整另行讨论。349 项前端测试、类型检查／生产构建、两套 fmt 与 diff 检查通过；这组说明已在隔离原生候选验证，并随 ac321b8 安装到本机 App。

用户已确认把《教父》短片段排查并入本目标：旧任务通过 App 删除，原媒体与隔离证据保留；不新增自动事后纠错。按 [0060](decisions/0060-overlap-alignment-before-acoustic-selection.md) 修复了重叠区双重排除，真实检查点重放恢复对白，新默认 58→59 段。人工听辨、其余失败点、完整长片及实际翻译质量仍待验收，见[短片段基线](godfather-short-baseline.md)。
