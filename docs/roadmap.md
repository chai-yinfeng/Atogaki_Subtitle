## 统一字幕编辑器：当前状态

按用户确认的“紧凑工作台、左视频、右波形与上下原译文、底部整宽字幕表格”实施，视频／波形独立折叠、三处分隔线可调、布局跨任务记忆。当前规则由 [0058](decisions/0058-compact-editor-and-playback-follow.md) 取代 0055 的旧布局和播放选择规则。

| 阶段 | 已交付 | 尚未完成 |
|---|---|---|
| 面板与交互 | 统一字幕编辑入口、默认跟随／手动锁定、草稿保护、搜索筛选、独立播放标记、紧凑上下双语编辑 | 真实长任务一次锁定触发未追溯；用户继续验收，不能用浏览器回归替代所有原生输入 |
| 性能与接口 | 28 px 虚拟摘要行、按 ID 局部保存、轻量任务摘要、完成任务停止全量轮询、波形缓存／请求代次、串行 seek；一万段连续滚动重复属性更新 12,147→0 | 滚动 P95 尚未证明改善；十分钟原生 RSS 跨负载变化，未通过稳定负载无持续增长；三小时 WAV 首次加载暂态保留观察 |
| 模块边界 | 当前段、列表、跟随、播放器、时间轴绘制／手势／波形请求、候选处理／历史／复核、字幕文件导出、单句／批量翻译、样式会话／字体视图、烧录会话／视图与工具生命周期；11 条 Rust 工作区命令；SQLite 编辑、发布／采用、只读查询模块 | 前端剩余处理／翻译配置、Rust 其余命令与 repository 渐进抽取；不改变事务或 schema |

最新工程基线：前端 102 项测试与相关 WebKit 专项、共享库 149 项测试／5 项环境依赖忽略、桌面 33 项／4 项环境依赖忽略。测试范围分别见[窗口验收](editor-workspace-validation.md)、[性能验证](editor-performance-validation.md)与 [0059](decisions/0059-desktop-command-and-repository-modules.md)，不同提交的结果不能合并成未执行的全平台验收。

上次正式 identifier 的本机覆盖记录为 `86c46c8`；之后滚动与 Rust 模块提交没有逐次重装。本机 App、恢复点与清理凭据见[安装记录](local-editor-installation.md)，公开发行仍为 macOS v0.1.2。正式数据库、人工评审、采用过的 ASR 证据、模型和来源不明文件不进入自动清理。

## 下一步与验收门禁

1. 继续按用例收敛 main.ts 与 Rust 边界，一条边界一个提交；下一步为翻译配置与剩余处理用例；烧录视图及专用确认已迁移，原生实际完成路径已有证据。保留唯一播放器、SubtitleDrafts、LocalDatabase 和 revision／候选事务。最新烧录会话已隔离异步访问并停止隐藏历史轮询，102 项测试及五组 WebKit 通过，详见[窗口验收](editor-workspace-validation.md)。
2. 原生保留字幕文件覆盖／Finder、批量确认、烧录运行中取消与覆盖确认验证；系统目录面板 Open 间歇禁用仍待调查。样式原生 AX 与真实 libass 初始预览、20 段原文 SRT 实际写入、60 秒合成视频实际烧录及成品规格已有证据。用可控的同负载原生操作复查滚动、稳定内存、锁定触发和工具卸载；保留原始 trace／RSS／数据核验，不把 DOM 减少或离页回收单独当作无泄漏结论。
3. 按[本机保留清单](local-artifact-retention.md)继续维护材料；本轮已将 v0.1.1／v0.1.2 的重复下载改为可追溯链接，并单独清理当前树 incremental 缓存，约 830 MiB 逻辑内容。未分类数据、工作数据库、模型、来源证据与共享缓存保留。Web／Postgres 只交付[影响报告](legacy-web-retirement-impact.md)，实施选择另行讨论。
4. 达到下一个可试用里程碑后完成隔离数据的签名包回归，再按已有授权更新本机 App。Windows 在选定候选独立实机验收，macOS 结果不外推。

## 产品与研究后续

原 P0–P5 的逐项合同与历史状态见[管线演进计划](pipeline-evolution.md)及[历史路线图](roadmap-history-2026-10-22.md#本轮处理管线与翻译质量)。下列保留待验证，不晋升为本轮新增功能：

- 固定真实短片段／完整长节目、少量人工参考和保留测试集；识别接缝、英文分段及人工听感继续验证，不从结构测试推导识别准确率。
- Hy-MT2／MLX／现有云端基线的人工盲评、完整任务峰值内存与 ASR 资源竞争；MLX 输出合同失败不降低标准。Windows 本地 runtime 与平台体验单独评估。
- 真实云端吞吐、限流／断网、Gemini 范围上传／删除与日英网络闭环、VAD 静音出字信号；服务／模型质量与 UI 工程回归分开。
- Windows 英语／韩语真实节目闭环、凭据、模型下载／代理、WebView2 媒体、字体与 libass、导出／烧录及悬浮字幕。悬浮字幕当前不稳定，不建议使用。
- 学习检索、多来源与文本 Anki 已有实现；长期收藏／回看使用验证及内建复习、复杂标签的产品优先级继续待讨论。多选、批量平移、频谱、逐帧、全局播放快捷键与复杂 ASS 不在当前编辑器改造验收内。
- 真实流式录音／系统音频采集、prefix 提交与会话后离线精修留在 CLI／research。跨设备同步、账号协作、云端托管、多租户、多轨和高级排版只在明确需求与独立决策后考虑。
