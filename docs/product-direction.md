# 产品方向：多语言音视频理解工作台

_最后更新：2026-08-09_

## 项目起点与泛化方向

Atogaki 最初为理解和学习ヨルシカ「後書き」电台而开发：把用户本机已有的节目音视频转成可定位、校对和复习的日中双语资料。这个具体场景决定了第一阶段对日语口语、人名/作品名词表、长节目上下文和时间轴校对的重视。

产品实现不得把某个艺人、节目或语言组合硬编码为唯一入口。日语电台仍是质量基线；在完成该场景的稳定闭环后，Atogaki 开始泛化为处理不同语言本地音视频的字幕识别、翻译、编辑与烧录工具。

Atogaki 是独立的个人开发工具，与ヨルシカ及其官方运营方没有隶属、授权或赞助关系。应用只处理用户在本机拥有或有权使用的媒体。

## 北极星

Atogaki 是一个本地优先的个人工具，帮助中文使用者理解、定位与复习外语音频和视频。字幕导出是结果之一，不是产品的唯一目标。

成功的体验是：听完一段外语节目后，用户能迅速回到任意一句，查看可信的原文与中文翻译，修正重要内容，并把它留作可复习的资料。

## 目标用户与场景

- 希望理解、校对和复习ヨルシカ「後書き」电台内容的中文使用者（首个具体场景）。
- 收听日语或英语电台、播客和录播节目的用户。
- 观看外语视频、节目和本地媒体的学习者。
- 需要保留双语字幕、片段或笔记供日后复习的个人用户。

首批支持语言组合为日语或英语识别、简体中文翻译。日语到简体中文继续作为首要质量基线；语言代码、任务存储、字幕轨道和 provider 适配不得假定固定语言组合。

## 两种产品模式

### 离线精修（第一优先级）

用户导入已经录制或下载到本机的媒体。应用使用本地识别模型生成带时间轴的原文转写，再翻译、校对与导出。

- 优先目标：正确性、可编辑性、可回看性。
- MVP 输入：本地音频和视频文件。
- MVP 输出：双语时间轴、SRT、ASS 和可选的带字幕视频。

### 实时辅助（第二阶段）

实时模式只提供低延迟的理解辅助，不承诺最终准确性。它应录制会话，并在结束后自动运行离线精修以得到最终结果。

- 可接受十几秒级延迟和较粗的转写。
- 优先展示原文粗转写；粗翻译仅作为可选提示。
- 任何实时结果都需要明确标注为“处理中/非最终版”。

## 产品原则

1. **本地优先。** 媒体、模型和任务默认留在设备上；云端翻译仅在用户选择并配置后使用。
2. **离线质量优先。** 不为了“实时”牺牲离线精修的正确性与上下文。
3. **时间轴是一等数据。** 每段字幕必须可定位、编辑、重放和导出。
4. **修正可以积累。** 用户对人名、术语和字幕的修正应进入词表或可复用的学习资料。
5. **媒体来源由用户提供。** 应用处理用户本机拥有或有权使用的媒体，不负责绕过网站限制或下载受限制内容。

## MVP：理解工作区

MVP 必须完成以下闭环：

1. 导入本地媒体，选择识别与翻译选项。
2. 在后台执行转码、转写、分段、翻译与导出，并反馈进度和错误。
3. 在同一页面播放媒体、跟随高亮当前字幕，并可点击字幕跳转。
4. 编辑原文和译文；原文改动后标记对应翻译为过期，并支持单段或全部重译。
5. 管理并应用词表；导出 SRT、ASS 和双语视频。

MVP 之外的功能：跨设备同步、协作、公共分享、账号体系、云端文件托管和多租户 Web 服务。

## 成功指标

- 用户可以在 10 秒内由字幕跳转回媒体中的指定句子。
- 对一段已完成的转写，修改原文、重译并导出无需重新运行 ASR。
- 本地任务失败时，用户可以看到失败环节与可操作的错误信息。
- 用户的词表能在后续任务中重复使用。

## 决策与变更规则

本目录中的计划是项目长期事实来源。改变目标用户、优先模式、存储策略或主要平台前：

1. 先更新本文件和 `docs/roadmap.md`，说明原因与影响。
2. 若是持久架构选择，在 `docs/decisions/` 新增决策记录。
3. 再开始实现；未记录的探索性代码不得成为默认方向。
