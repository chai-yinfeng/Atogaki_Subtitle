# 桌面 App 稳定能力矩阵

_冻结日期：2026-09-18_

当前桌面 App 面向本地文件的转录、翻译、校对、学习和导出。它保留四种 provider 组合需要的基础能力，但云端 ASR 目前只用于用户明确选择范围的候选修复，不作为新任务的全片默认入口。

| 层级 | 本地路线 | 云端路线 |
| --- | --- | --- |
| ASR | Whisper.cpp：新任务全片识别、selected-range 独立 run、VAD、词表提示、GPU→CPU 回退 | Gemini 3.5 Transcribe：selected-range 独立 run、真实 word timestamps、可选 speaker 数据、每次范围单独授权上传 |
| Translation | Hy-MT2 1.8B／7B：App 管理模型，受管 loopback `llama-server`，translation groups 与结构门禁 | DeepL、DeepSeek、Gemini、OpenAI-compatible：系统凭据、translation groups、上下文／revision 校验 |

因此当前可验证的组合是：

1. Whisper → Hy-MT2：完整本地路线。
2. Whisper → 云端 translation：本地音频识别，只有原文、上下文和词表保护数据发送给翻译 provider。
3. Gemini selected range → Hy-MT2：云端生成候选原文，经用户采用后在本地翻译。
4. Gemini selected range → 云端 translation：云端 ASR 与云端翻译分别授权；选择其中一个不会自动授权另一个。

桌面 App 同时稳定保留任务队列、run／质量信号审查、字幕与时间轴编辑、translation stale 保护、学习资料、SRT／ASS 导出和视频烧录。

字幕校对使用同一紧凑工作面：左侧视频，右侧波形时间轴与上下排列的原译文编辑，下方整宽虚拟列表；视频／波形独立折叠，面板比例可调。默认跟随播放，手动选择或聚焦编辑后锁定，恢复前保护草稿与时间输入。完整识别任务直接进入字幕编辑，处理中任务保留只读进度；翻译、复核与导出按需打开。当前交互以 [0058](decisions/0058-compact-editor-and-playback-follow.md) 为准，生命周期见 [0057](decisions/0057-editor-view-lifecycles.md)，模块整理不扩大平台或制作能力范围。

收听页提供节目列表、播放器与全文阅读，使用上一句／下一句、±5 秒、播放暂停和倍速；循环、A/B 与句首／句尾试听仅保留在编辑工作流。学习区的 Anki 导出为当前语言单词本的 TSV 文本资料，包含收藏文本、填写的词义、来源例句／译文、节目名、时间码、语言与类型，不嵌入音视频。

以下能力不进入当前桌面范围：Gemini 全片新任务、Gemini Live、Muse Voice Transcribe、实时音频采集、E2E live translate、新 ASR／MT 模型试验、可变 prefix-commit policy，以及只为跑 benchmark 暴露的参数。它们先通过 CLI/evaluation harness 产出可复现 artifact 和报告。

## 桌面晋升门禁

CLI 实验进入 App 前必须给出固定输入、配置快照、质量对比、性能和资源数据、失败恢复、隐私边界及迁移方案。结构合同测试不能替代真实质量结论。晋升需要单独的产品决策，不因 core 已实现 provider 就自动增加 UI 入口。

## 2026-10-18 开发分支扩展

本轮由用户明确批准，按 [0045](decisions/0045-resumable-offline-workflows.md) 扩展稳定工作流；不表示既有公开安装包已包含这些能力。

- 长音频约 120 秒归属区间、前后最多 5 秒音频上下文，完成块经摘要校验后原子提交；失败／暂停在同任务内手动继续。进度轮询独立于执行，避免 SQLite 事务互相等待。
- 只读部分原文、任务级翻译配置、独立自动翻译阶段、后端配置草稿隔离与不可变执行快照。
- 持久 ASR 候选重开／比较／采用、完整本地候选、范围授权和取消；Gemini 取消先等待上传清理，不声称能撤回已发送的数据。
- 任务与字幕搜索、学习检索及来源筛选、编辑器循环／衔接试听、多文件导入、命名预设、完整来源例句、收藏高亮和 Anki 文本 TSV。
- MLX Whisper 仅 CLI 可选；Hy-MT2 MLX 仅 evaluation harness。没有通过结构合同的结果不会写入正式字幕。

模型、真实长节目接缝、人工翻译盲评、Windows 实机与公开发行的验收边界见 [离线工作流验证](offline-workflow-validation.md)。


2026-10-30 交互补充：收听全文可置于右侧、下侧或收起，分隔比例支持鼠标／键盘并记忆，保留唯一播放器。局部重新识别支持波形与字幕轨道图形选区、起止手柄与精确输入同步、覆盖原文、显式完整块对齐及共享播放器试听；图形调整只改处理范围，不改已有字幕。编辑工具使用独立中性色与清晰分区。上述交互不扩大 ASR、字幕 schema 或云端授权范围。

2026-10-30 复核试用修正：复核与主编辑器使用同一时间轴面板和控制状态，返回保留视窗与播放位置；暂停播放头常驻。识别起止可独立调整，显式对齐在空白区向外寻找第一处字幕边界，无边界使用媒体头尾，取代仅扩展相交字幕块的旧交互。

2026-10-30 候选清理补充：清理成功后从历史候选列表移除，失败显示原因并允许重试；已清理旧记录仅有真实残留才展示重试。后台运行摘要和来源关系保留，原始／已采用识别继续受保护。
