# 普通波形定位错误暂停视窗跟随

日期：2026-10-28。用户在本机 0cf72c0 反馈播放时音轨不随播放头移动，截图状态为“视窗已暂停”。

原手势模块在任何有效 pointerdown 及背景 click 时调用 stopFollowing，因此普通点击定位、只选择字幕块、拖动播放头都会关闭波形跟随；即使没有实际平移视窗，后续播放也会保持暂停状态。原文字提示只能通过顶部全局跟随恢复，还会切换编辑对象并受到未保存时间保护。

修复后，普通定位、未改变时间的选段和播放头拖动保留原跟随意图。真正的平移、时间调整、缩放、翻页仍暂停；捕获手势期间暂不自动居中，避免拖动中视窗移动。波形区状态改为可访问的独立开关，暂停后显示“恢复视窗跟随”，只恢复视窗、不切换锁定编辑段或提交时间草稿；顶部全局跟随继续恢复完整跟随。

新 verify-editor-wave-follow.cjs 在修复前通过真实 WebKit 点击复现状态变为暂停；修复后覆盖普通定位、实际播放越过两秒视窗、只选字幕、播放头拖动期间视窗稳定、实际平移暂停、独立恢复及锁段／时间草稿保留。gestures、timeline、follow、time-navigation、waveform-follow-boundaries 五组既有回归通过，前端 346 项／类型／生产构建、两套 fmt／diff 通过。首次类型检查发现 querySelector 返回 Element 不含 title，明确按钮类型后生产构建通过。
