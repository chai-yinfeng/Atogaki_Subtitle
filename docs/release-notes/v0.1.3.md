# Atogaki v0.1.3 — macOS Apple Silicon

本版统一字幕编辑工作面，完善图形化复核和收听布局。仅发布 macOS arm64 安装包；Windows 继续使用已有版本，本轮不包含 Windows 更新。

## 字幕编辑与复核

- 完整识别的任务直接进入统一编辑器：视频、波形时间轴、上下排列的原译文编辑框和紧凑字幕列表；视频／波形可折叠，面板比例可调并记忆。翻译、词表、复核与导出按需打开，返回保留编辑位置。
- 默认跟随播放，手动选段或输入后锁定编辑对象；播放位置和编辑段分别标记。支持文本搜索及未翻译、过期、待复核筛选，筛选不会丢弃当前草稿。
- 长字幕使用虚拟列表和局部更新；完成任务不再周期性读取全部字幕证据。音频按需加载，保留播放位置恢复；优先播放原媒体，失败时自动回退到任务音频。
- 复核与主编辑器共用时间轴、缩放和播放头。可按住拖动重新框选，或沿整条起止线独立调整边界；支持精确输入、试听和向外对齐到字幕边界，先对照候选再确认采用。
- Ctrl+Z／⌘Z 按焦点作用：文字输入内撤销文字，输入框外撤销打轴／结构操作；继续保留独立历史。结构撤销恢复来源与翻译依赖，历史仅在当前 App 会话有效。
- 清理成功的未采用候选退出历史列表；失败或真实残留可重试。后台摘要、原始识别和已采用来源证据保留。

## 收听、识别与导出

- 收听全文可放右侧、下侧或收起；当前双语字幕始终在视频下方。去掉视频固定高度上限，视频高度与全文比例可拖动调整并记忆，保持画面原比例和同一播放器。
- 收听操作精简为上一句／下一句、±5 秒、播放暂停和倍速；循环与衔接试听保留在编辑器。
- 修复重叠音频块接缝可能双重排除对白的问题，无法可靠对齐的内容保留供复核；英文新任务使用语言对应的默认切分，不自动改写旧任务。
- 短翻译组可打包请求，保留逐组恢复、revision 校验和人工编辑保护；新增消耗与缓存观测。没有调整翻译模型上下文窗口，也不保证实际费用或译文质量改善。
- 导出优先推荐 SRT／ASS 配合原视频播放。烧录会重新编码、可能损失画质；视频码率档位不保证保真，覆盖已有输出前明确确认。

## 安装与验证范围

下载 `Atogaki-v0.1.3-macos-arm64.dmg` 及相邻 `.sha256`。覆盖安装保留任务、字幕、学习数据和模型；模型不内置，云端凭据仍保存在 macOS Keychain。最低声明 macOS 12.0，日常质量基线为 Apple Silicon。

App 使用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。本机交互由用户分批体验确认，相关前端、Rust／Tauri 和隔离窗口检查有记录；不将这些结果外推为 Windows 验收、严格原生性能指标或完整长片翻译质量证明。综合复核脚本末尾的任务导航仍有间歇超时记录；本次清理相关检查通过。

本项目代码采用 Apache-2.0。App 附第三方许可证和构建清单；`Atogaki-0.1.3-third-party-sources.tar.xz` 及相邻校验文件提供 FFmpeg、whisper.cpp、llama.cpp 与静态字幕栈的对应源码，不含模型权重。
