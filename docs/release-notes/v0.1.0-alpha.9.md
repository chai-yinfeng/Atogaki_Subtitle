Atogaki v0.1.0-alpha.9 是仅面向 macOS Apple Silicon 的预发布版本，集中修复《響け！ユーフォニアム》节目转录、长节目 DeepSeek 翻译恢复、局部重新识别和本地视频播放问题，并补充带字幕视频的导出规格预览。

## 本轮更新

- 新增日语《響け！ユーフォニアム》内置词表，覆盖作品名、主要角色、声优、监督／脚本等核心制作人员及 OP／ED 相关歌手；针对 `U4`、`eupho`、`UFO` 等实际误识别加入确定性修正规则。
- 修正 Whisper 提示词组装：不再把 `读音（表記: 正字）` 说明文本送入转录，也不再未经用户允许按启发式长度截断所选词包；单独出现的 `ユーフォ`／`ユーフォニアム` 不再被误当作必须保留原文的专名。
- 字幕编辑新增选定时间范围重新识别：使用原任务模型和参数、隔离前文文本上下文，先并排预览原字幕与候选结果，再由用户确认原子替换；不会自动扩大范围或覆盖预览期间的新编辑。
- 全部翻译改为可恢复批次：每个成功批次立即写入 SQLite，后续网络或结构错误不再清空已完成结果；再次执行只续跑缺失或过期段。
- DeepSeek 的空译文会单独补充请求一次；仍为空时保留为待翻译而不阻塞后续批次，并在界面指出具体段号和时间。`11/12` 等数量错误仍拒绝当前批次，避免错配稳定字幕 ID。
- 不同任务可并行翻译，同一任务内部继续串行，任务切换不会阻止另一个节目的翻译或混淆进度。
- 修复长视频在 macOS WebView 中画面可播放但音轨静默的问题：原媒体通过受令牌保护的专用 Range 协议读取，正确支持单段、多段和 HEAD 请求，不复制原视频，也不使用双播放器强行同步转录 WAV。
- 带字幕视频增加省空间、均衡和高质量三档；均保持原分辨率，并在提交前显示目标视频码率、预计成品大小和估算依据。三档当前分别约为源码视频码率的 75%、120% 和 180%，低码率源仍可能出现二次编码损失。
- 本地测试打包在新候选通过校验后自动清理旧的 Atogaki DMG 与校验文件，避免测试目录持续堆积。

## 安装与配置

1. 下载 `Atogaki-v0.1.0-alpha.9-macos-arm64.dmg` 及相邻 `.sha256`，使用 `shasum -a 256` 核对。
2. 本版本面向 Apple Silicon，最低声明 macOS 12.0。App 采用 ad-hoc 签名且尚未公证，首次打开可能需要在 Finder 中右键选择“打开”。
3. Whisper、Silero VAD 和离线词典包不包含在 DMG 中；已有任务、词表副本和 SQLite 工作区保留在应用数据目录，不随覆盖安装删除。
4. DeepSeek、DeepL 和其他 OpenAI-compatible 翻译为可选云端能力；API Key 保存到 macOS Keychain，不写入任务 SQLite 或日志。

## 已知限制

- 本版本不提供新的 Windows 安装包；现有 Windows 用户继续使用 v0.1.0-alpha.6。新增播放器协议、重新识别和导出规格界面需在下一次 Windows 候选中完成实机验证。
- 硬字幕必须解码、绘制字幕并重新编码视频。质量档保持像素尺寸，但对本身码率极低的视频，按源码率比例提高码率仍不能保证无可见的二次压缩损失；界面显示的是目标码率和估算大小，不是无损承诺。
- Whisper 在低信息、重复音节或长尾音频中仍可能产生幻觉循环；本版提供局部重新识别与预览替换，但不会自动删除真实语音内容。
- App 未使用 Developer ID 签名或公证，首次打开可能出现 Gatekeeper 提示。

## 测试反馈

请附 macOS 版本、设备型号、媒体封装与编码、使用模型、词包选择、复现时间范围和完整错误文本。播放器无声问题请同时说明原文件在系统播放器中是否有声音；翻译问题请提供段号和错误，不要包含 API Key、代理凭据或私人媒体内容。

Atogaki 自有源码采用 Apache-2.0。DMG 内包含第三方许可证和构建清单；同一 Release 的对应源码包提供 FFmpeg、whisper.cpp 与静态字幕栈的精确源码和重建材料。
