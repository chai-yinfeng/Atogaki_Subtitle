Atogaki v0.1.0-alpha.10 是面向 Windows 11 x86_64 的未签名预发布版本，将 Windows 从 alpha.6 同步到当前共享功能基线，并修复候选测试中发现的字幕样式预览问题。

## 本轮更新

- 同步学习区与词典：支持收藏词语、语法和整句、返回来源播放、日英韩分册，以及用户自行下载的 JMdict、Tomoshi、ECDICT 和可选在线词典凭据。
- 同步任务级字幕样式与字体浏览：原文／译文可独立设置字体、字号、颜色、描边、背景、位置和边距，并使用 FFmpeg/libass 生成真实预览。Windows FFmpeg 没有 PNG encoder 时会自动使用内置 MJPEG，不再导致预览空白；错误摘要会展示实际 FFmpeg 错误而不是版本 banner。
- 同步工作台拖动／键盘排序、模型 HTTP Range 断点续传、日语《響け！ユーフォニアム》词表及 `U4`／`UFO` 确定性修正。
- 同步可恢复云翻译：DeepSeek 等 provider 每个成功批次立即写入 SQLite，再次执行只处理缺失或过期段；空译文保留为待修复并指出段号，不同任务可以并行翻译。
- 同步选定范围重新识别：复用原任务模型与参数、隔离文字上下文，先预览候选，再确认原子替换。
- 同步长视频 Range 播放修复：任务媒体由受令牌保护的本地协议读取，不复制原视频；WebView2 可按范围读取后段音视频。
- 同步带字幕视频的省空间、均衡和高质量三档；保持原像素尺寸，在提交前显示目标码率与预计大小。Windows 使用内置 LGPL MPEG-4 软件编码。
- 恢复并固定 Windows NSIS current-user 安装、中英文安装器、ICO、Credential Manager 提示、`Ctrl+B` 快捷键和平台中性的 Whisper 日志。
- Windows 构建门禁现在不仅检查 `ass` filter 和 encoder 名称，还会在安装后实际使用 DirectWrite/libass 渲染一张字幕预览图片，再执行 sidecar、合规资源和卸载检查。

## 安装与配置

1. 下载 `Atogaki-v0.1.0-alpha.10-windows-x86_64-setup.exe` 及相邻 `.sha256`，在 PowerShell 使用 `Get-FileHash -Algorithm SHA256` 核对。
2. 本版本没有商业代码签名，Windows SmartScreen 可能显示“未知发布者”。只有在确认文件来自本 Release 且哈希一致后，才在“更多信息”中选择继续运行；不要全局关闭 SmartScreen 或杀毒软件。
3. Whisper、Silero VAD 和离线词典包不包含在安装器中，请在设置页按需下载或选择已有文件。Whisper 当前使用 CPU，不包含 CUDA 或 DirectML 后端。
4. DeepL、DeepSeek、OpenAI-compatible 和在线词典 API Key 保存到 Windows Credential Manager，不写入任务 SQLite 或日志。

## 已知限制

- **Windows 悬浮字幕当前不稳定，不建议使用。** 已知表现包括点击没有反应，以及主窗口消失后找不到悬浮窗口或恢复入口、只能从任务管理器结束进程。本版本按既定范围不修复该功能。
- Windows 带字幕视频使用 LGPL MPEG-4 Part 2 软件编码。部分 Windows“媒体播放器”版本可能先提示编码格式不受支持，但仍能继续播放并显示烧录字幕；播放器兼容性也可能受到源音频直通格式影响。重要交付请先在目标播放器复核，必要时使用兼容播放器或另行转码。
- 视频导出需要解码、绘制字幕并重新编码。三档保持分辨率，但低码率源仍可能出现可见的二次压缩损失，预计大小不是无损或精确体积承诺。
- 正式测试范围为 Windows 11 x86_64；Windows 10 仅做尽力兼容，Windows ARM64 尚不支持。
- 安装包未签名，SmartScreen 提示属于当前 alpha 的已知交付边界。

## 测试反馈

请附 Windows 版本与 OS build、CPU、内存、媒体封装与编码、模型、复现步骤和完整错误文本。视频播放器提示请同时提供导出记录中的视频编码器与音频处理方式；截图或日志中不要包含 API Key、代理凭据或私人媒体内容。

Atogaki 自有源码采用 Apache-2.0。安装包内包含第三方许可证和构建清单；同一 Release 的 Windows 对应源码包提供 FFmpeg、whisper.cpp 与静态字幕栈的精确源码和重建材料。
