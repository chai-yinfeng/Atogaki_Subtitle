# Atogaki v0.1.1 — macOS Apple Silicon

包含本机 v0.1.0 候选及用户试用后的界面修正。v0.1.0 tag 保留为历史候选，不创建 Release，也不移动 tag。

首个稳定版集中完善长节目恢复、识别候选、字幕校对、翻译和学习闭环。本次仅发布 macOS Apple Silicon 安装包；Windows 继续使用已有 `v0.1.0-alpha.10`，不宣称本轮改动已完成 Windows 实机验收。

## 主要改进

- 本地识别按约两分钟提交持久检查点。支持暂停、重启后手动继续、只读部分原文；后续块或发布阶段失败不会丢弃已提交识别结果。旧历史任务无检查点时明确提示只能重试。
- 翻译冻结任务与执行配置，支持 Hy-MT2 本地翻译、DeepSeek、DeepL、Gemini 及高级 OpenAI-compatible。中断后可补缺失／过期译文，也可明确选择全体重译；人工译文有覆盖保护。Gemini 识别与翻译共用同一 provider 凭据，音频上传另行授权。
- Whisper 全片／局部候选和 Gemini 局部候选持久保存，可比较、采用和清理。增加当前播放头字幕范围选择；候选替换允许目标范围内预期重叠，同时保护范围外字幕。
- 字幕文字自动保存并支持撤销，保存一段不再丢失其他段草稿。高级编辑支持插入、删除、切分、合并和精确时间调整；增删仅使实际受影响的翻译失效。复核提示支持定位与隐藏已处理记录。
- 完善批量导入、任务预设、全文检索、循环试听、学习检索、多来源例句、收藏高亮和文本 Anki TSV 导出。
- 提供月夜／来信主题与本机图片导入。提取最多 12 个代表色，通过一份共享色盘分别选择场景底色、阅读面色和按钮强调色。指向／键盘聚焦显示近似色名、并排色块、明暗关系与派生效果，点击才应用；不上传图片。移除月猫专用入口，已有图片可通过通用导入继续使用。
- 设置页修复滚动内容穿过导航和保存栏的问题，采用中间独立滚动；Gemini 翻译项统一为“LLM API”。Hy-MT2 1.8B 标为本地翻译推荐，7B 保留简明名称，说明资源与耗时取舍。

## 安装

下载 `Atogaki-v0.1.1-macos-arm64.dmg` 和相邻 `.sha256`，核对 SHA-256 后打开，将 App 拖入 Applications。覆盖安装保留原任务、人工字幕、词表、学习数据和模型。

声明最低 macOS 12.0；当前完整体验基线是 Apple Silicon macOS。App **采用 ad-hoc 签名，尚未使用 Developer ID 签名或 Apple 公证**，首次打开可能需要在系统“隐私与安全性”中允许运行。不要全局关闭 Gatekeeper。

Whisper、VAD、Hy-MT2 模型和词典数据均不包含在 DMG。云端能力需要用户自行配置 Key，凭据保存在 macOS Keychain。云端翻译发送字幕文本及必要上下文；Gemini 识别只有在用户明确确认确切范围后才上传所选音频。

## 验收边界与限制

- 桌面保持 C++ / Metal 路线，MLX 实验暂缓，未纳入安装包或默认 runtime。
- 自动配色只能提取与派生颜色，不能自动复现作品笔触或艺术构图；用户导入素材的使用权限由用户自行确认，安装包不含官方专辑或演出图片。
- 长节目接缝听审及翻译人工质量验收仍需补充；工程恢复测试通过不代表所有内容的识别或译文准确性已获保证。局部识别候选需要明确采用。
- Hy-MT2 7B 在部分设备上较慢，选择较小模型或云端翻译时应按实际体验决定。没有宣称量化、本地模型或 MLX 具有准确率优势。
- Windows 本轮仅维护共享编译检查，未生成新安装包。macOS Intel 不提供安装包。

Atogaki 自有代码采用 Apache-2.0。App 内含第三方许可证与构建清单；同一 Release 提供 `Atogaki-0.1.1-third-party-sources.tar.xz` 及 SHA-256，覆盖 FFmpeg、whisper.cpp、llama.cpp 与静态字幕栈的精确源码和重建材料，不含模型权重。
