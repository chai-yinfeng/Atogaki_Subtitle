# Atogaki v0.1.4：macOS 更新起始版

适用于 Apple Silicon。首次从旧版本迁移，请下载 DMG 并将 Atogaki 拖入「应用程序」。安装包采用 ad hoc 签名、未公证；macOS 可能要求在「隐私与安全性」允许打开或重新授予系统音频录制权限。模型和 Python/MLX 运行环境不随包分发。

- 离线任务可选 Qwen3-ASR 与强制对齐；本机模型可命名导入。在线字幕提供 One Pass 和 Two Pass，模型与语言适用范围见应用内「使用说明」。
- 调整工作台、收听、字幕编辑、图片主题与浮窗；收听切回可恢复暂停位置，在线译文原样定稿不重复等待。
- 字幕编辑工具栏更紧凑，时间轴可显示手动 A/B 循环的起止点与范围。
- 使用百日红信纸图标，包含新版 macOS 图标资源。
- 加入签名更新入口。从本版开始可以在「设置 → 更新」检查更高版本。检查与安装由用户触发，安装后重启。

校验 DMG 请使用同名 SHA-256 文件。第三方 sidecar 的对应源码及许可证请见本次发行资产。
