Atogaki v0.1.0-alpha.6 是首个面向朋友扩展测试的 Windows x86_64 预发布版本。

## 本轮更新

- 新增 Windows 11 x86_64 的 current-user NSIS 安装包，不要求管理员权限，也不要求预装 Rust、Node、FFmpeg、Whisper 或 MSYS2。
- 内置 CPU 版 whisper.cpp，以及带 libass 的 LGPL-only FFmpeg／ffprobe；支持识别、字幕导出和 MPEG-4 软件烧录闭环。
- 支持 Windows Credential Manager、应用数据目录、模型下载与代理设置、WebView2 播放、原生文件选择和 Explorer 定位导出结果。
- 主程序使用 Windows GUI 子系统，Whisper／FFmpeg／ffprobe 后台调用不再附带无用途的终端窗口。
- 保留 v0.1.0-alpha.5 的字幕编辑、任务内时间轴、DeepL／DeepSeek／OpenAI-compatible 翻译、词表、收听区和悬浮字幕能力。

## 安装与配置

1. 下载 `Atogaki-v0.1.0-alpha.6-windows-x86_64-setup.exe` 及相邻 `.sha256`，在 PowerShell 使用 `Get-FileHash -Algorithm SHA256` 核对。
2. 本版本尚未购买商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。只有在确认文件来自本 Release 且哈希一致后，才在“更多信息”中选择继续运行；不要全局关闭 SmartScreen 或杀毒软件。
3. Whisper 与 Silero VAD 模型不包含在安装包中，请在设置页下载或选择已有模型。
4. 云端翻译为可选功能；DeepL、DeepSeek 或 OpenAI-compatible API Key 保存到 Windows Credential Manager，不写入任务 SQLite。

## 支持范围与已知限制

- 正式测试范围为 Windows 11 x86_64；Windows 10 目前仅做尽力兼容，Windows ARM64 尚不支持。
- Whisper 首版使用 CPU；尚未提供 CUDA 或 DirectML 加速。
- 视频硬字幕使用 LGPL MPEG-4 软件编码，速度、体积和画质可能不如平台硬件 H.264；请反馈真实媒体结果。
- 安装包未签名，因此 SmartScreen 提示属于当前 alpha 的已知交付限制。
- macOS 仍是日常核心开发和交互质量基线；Windows 版本在选定稳定候选节点集中更新。

## 测试反馈

如发现问题，请附 Windows 版本与 OS build、CPU、内存、媒体类型、使用模型、复现步骤和完整错误文本。截图或日志中不要包含 API Key、代理凭据或私人媒体内容。

Atogaki 自有源码采用 Apache-2.0。安装包内包含第三方许可证和构建清单；同一 Release 的 Windows 对应源码包提供 FFmpeg、whisper.cpp 与静态字幕栈的精确源码和重建材料。
