Atogaki v0.1.0-alpha.8 是仅面向 macOS Apple Silicon 的预发布版本，完成了学习区首个可用闭环，并加入任务级字幕样式、真实渲染预览和工作台任务排序。

## 本轮更新

- 新增学习区：可从收听全文中选择单词、短语或语法片段，保存原句与媒体时间，并按日语、英语、韩语分册管理和返回原任务播放。
- 新增多来源词典详情与简明释义提升：支持离线 JMdict、Tomoshi、ECDICT，以及 Merriam-Webster API；词典包由用户下载到正式应用数据目录，API Key 保存到系统凭据库。
- 模型下载支持断点续传；词典查询失败不再锁死来源切换，ECDICT 可利用词形索引查询常见英语变形。
- 新增任务级原文／译文字幕样式：字体、字号、粗斜体、颜色与透明度、描边、阴影、背景、位置、边距和字间距均可配置。
- 字幕样式使用 FFmpeg／libass 生成真实预览，并与双语 ASS 导出、视频烧录共享同一套样式序列化结果；字体浏览器提供完整字体列表和实际文字样张。
- 工作台任务列表支持持久化排序，提供整张卡片鼠标／触控板拖动、六点手柄和键盘上下方向键三种入口。
- Cambridge 词典因官方确认当前 API 不可用而从产品路径移除；ECDICT 实机验证后取代覆盖不足的 FreeDict。

## 安装与配置

1. 下载 `Atogaki-v0.1.0-alpha.8-macos-arm64.dmg` 及相邻 `.sha256`，使用 `shasum -a 256` 核对。
2. 本版本面向 Apple Silicon，最低声明 macOS 12.0。App 采用 ad-hoc 签名且尚未公证，首次打开可能需要在 Finder 中右键选择“打开”。
3. Whisper、Silero VAD 和离线词典包不包含在 DMG 中，请在设置页按需下载或选择已有文件。
4. 云端翻译与 Merriam-Webster 为可选功能；API Key 保存到 macOS Keychain，不写入任务 SQLite。

## 已知限制

- 本版本不提供新的 Windows 安装包；本轮窗口和界面交互将在 Windows 实机回归后使用后续版本发布。现有 Windows 用户应继续使用 v0.1.0-alpha.6。
- Collins 目前只有待接入边界，没有可用查询 adapter；Cambridge 已移除，不应视为受支持来源。
- 精确到单词的音频裁剪、学习区检索／筛选、复习系统和 Anki 导出尚未实现。
- App 未使用 Developer ID 签名或公证，首次打开可能出现 Gatekeeper 提示。

## 测试反馈

请附 macOS 版本、设备型号、媒体类型、使用模型、复现步骤和完整错误文本。字体或字幕问题请同时提供所选字体、预览截图与导出格式；截图和日志中不要包含 API Key、代理凭据或私人媒体内容。

Atogaki 自有源码采用 Apache-2.0。DMG 内包含第三方许可证和构建清单；同一 Release 的对应源码包提供 FFmpeg、whisper.cpp 与静态字幕栈的精确源码和重建材料。
