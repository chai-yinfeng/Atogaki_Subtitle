# Atogaki v0.1.2 — macOS Apple Silicon

本次发布修复长电影断点恢复，并加入按阶段并发、稳定前缀提前翻译及累计执行计时。仅提供 macOS arm64 产物，Windows 继续使用 v0.1.0-alpha.10。

## 修复与改进

- 修复中断后继续把等待时间计入处理用时的问题，改为累计各次执行时间；退出异常后以最后活跃心跳停止计时。提前翻译按组更新成功数量，新尝试清除旧错误提示，识别完成后仍在翻译不会被描述为识别错误。旧版已混入等待的历史历时可能无法完整还原。
- 修复长电影在 Whisper / VAD 读取块末尾出现轻微时间越界时停止、继续后在同一位置失败的问题。保留原始识别证据，由下一块负责右侧上下文；有效检查点继续复用。任务列表增加可展开的失败原因、块范围及产物位置。
- 默认允许两个任务同时进行本地 Whisper 识别。各任务内部仍按约两分钟有序提交检查点；暂停与继续等待旧执行结束，避免重复运行。
- DeepSeek 每次翻译最多并发四个语义分组，自动与手动云端翻译共用四个请求名额；云端翻译可以与 Whisper 同时进行。本地 Hy-MT2 在识别完成后独占设备翻译。
- 选择自动云端翻译时，可在同一任务的稳定原文前缀上提前翻译；保留最新识别块及后文缓冲，只处理完整语义分组。开场静音和长句可能推迟首次翻译。
- 提前翻译结果和实际请求记录持久保存，完整识别后核对输入、上下文、配置和 revision 才复用。翻译失败保留成功分组，让识别完成；之后继续只补翻译，不重跑识别，不覆盖期间的人工编辑。

## 安装与边界

安装包为 `Atogaki-v0.1.2-macos-arm64.dmg`，相邻 `.sha256` 用于校验。覆盖安装保留原任务、字幕、学习数据和模型。已中断的任务需要用户手动点击“继续”；不会在启动时自动占用设备。

最低声明 macOS 12.0，完整体验基线为 Apple Silicon。App 采用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。模型不包含在安装包；云端凭据保存在 macOS Keychain。提前云端翻译只发送用户所选任务的字幕文本及上下文，Gemini 音频上传继续单独授权。

工程验证包括真实 202:52.757 影片断点恢复、两个八分钟 Metal 任务并发与本地模拟翻译、缓存损坏及中断恢复、输入 revision 冲突和隔离窗口。模拟翻译测试不代表真实云端限流或译文质量已验收；长时间双任务压力、人工接缝听审及翻译质量仍待补充。并发不保证吞吐翻倍，实际速度与内存占用取决于设备和模型。

英文字幕目前仍可能被 32 字符长度限制切成短片段；本轮未修改英文切分或合并既有字幕，后续单独改进。

MLX 暂缓；本版继续使用 C++ / Metal。未构建 Windows 或 Intel 安装包，未宣称跨平台实机验收完成。

Atogaki 自有代码采用 Apache-2.0。App 包含第三方许可证与构建清单；对应源码包 `Atogaki-0.1.2-third-party-sources.tar.xz` 及 SHA-256 覆盖 FFmpeg、whisper.cpp、llama.cpp 与静态字幕栈，不含模型权重。
