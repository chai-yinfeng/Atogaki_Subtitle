# Atogaki v0.1.6

适用于 Apple Silicon，最低 macOS 12.0。已安装正式版 v0.1.4 的用户可在「设置 → 更新」检查并安装，安装后重启。首次安装请下载 DMG，把 Atogaki 拖入「应用程序」。

- **日语学习。** 在「收听」点词或框选日语字幕，可查看读音、词典形、释义与句型的中文说明，并收藏后回听。句型分析支持跨相邻字幕选择。自动识别暂未覆盖的表达，可以在「学习 → 日语语法」按句型或 JLPT 等级查阅。词典与分词包可在「设置 → 词典」按需安装。
- **全屏收听。** 视频进入全屏后仍可显示原文、译文或双语字幕。
- **字幕和视频导出。** 可以单独导出 SRT、ASS 或带可切换字幕轨的 MKV。烧录视频可以直接导出；需要后期压制时，可先导出画质优先 MP4 或 ProRes 中间文件。

DMG 采用 ad-hoc 签名，未公证。macOS 可能要求允许打开 App 或重新授权系统音频录制。识别模型、词典和 Python／MLX 运行环境按需准备。可用同名 SHA-256 文件校验 DMG，随附的对应源码归档包含第三方组件的源码与许可证。
