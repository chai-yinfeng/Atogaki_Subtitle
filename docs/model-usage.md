# 模型与使用说明

更新：2026-11-17。本文面向使用者；在线部分描述当前开发试用版，不代表已发布 v0.1.3 的能力。App 内的集中说明入口尚未接入。

## 如何选择识别模式

One Pass 使用 Qwen3-ASR 1.7B 8-bit 与配套 DFlash 加速包，直接显示可修订原文。不需要下载 SenseVoice；DFlash 也不是可以单独转写的模型。它加快解码，不保证每段都更快，也不保证识别正确。

Two Pass 先显示草稿，再由 Qwen 识别完整语音段并确认。草稿会被替换，早出现的文字不一定是最终结果。

- SenseVoice 周期性重新识别累积音频，提供连续更新的草稿；它不是原生流式模型，语音持续变长时会有重算成本，不能保证比 One Pass 延迟低。
- Zipformer 使用原生流式识别。当前有中文、英语、韩语的独立模型，尚无本项目验证过的日语模型。
- SenseVoice → Qwen 当前开放中文、日语、英语、韩语，不代表支持 Qwen 的全部语言。主要质量反馈来自日语电台，其他语言没有同等验证结论。

模型列表中的“推荐”用于帮助选择，不限制其他候选的展开、下载或使用。同一系列直接列出各体积／量化档。

## VAD 能做什么

VAD 检测哪里可能有人声，用于减少静音识别和寻找语音段边界。它不理解句子的意思，不保证排除音乐、人声采样或环境声，也不能提供词与音频的精确对应。

切段太积极可能截断吞字、气声或句尾；等待停顿更久会增加延迟。VAD 的气口、模型确认和译文分组是不同环节，最终字幕可能晚于停顿出现。

离线 Whisper 的 GGML VAD 与在线 ONNX VAD 使用不同格式，不能互换。下载或导入时选择对应用途。

## 模型体积、速度与正确性

Whisper Medium 是本项目日语离线工作的常用选择。用户反馈 Large 系列在部分电台素材上更易重复；不能由参数更多或文件更大推断它一定更好。

Qwen3-ASR 0.6B 和 1.7B，以及完整／4-bit／8-bit 权重，提供不同的磁盘、内存和计算取舍。量化位数描述权重存储，不代表整套计算都使用该位数；模型文件大小也不是运行内存上限。

当前本机开发试用版已补齐离线 Qwen 入口与完整打轴；稳定 Release 状态需看路线图。选择离线 Qwen 还需要准备 Qwen3-ForcedAligner 0.6B（约 1.84 GB）及本地对齐运行环境，缺失时该选项不可用。ForcedAligner 将已经识别的文字对齐到音频，不是第二次翻译，也不能保证修正误听。

离线 Qwen 在识别和打轴完成后开始翻译；Whisper 的部分云端后端支持识别期间提前翻译。

本地翻译需要与识别分享算力。更快的 ASR 不一定让译文同幅度变快；较长上下文可能改善理解，也增加等待和内存占用。中文可修订草稿与定稿分开看待，定稿不是正确性认证。

## 芯片与加速范围

| 路径 | 当前适配 | 使用边界 |
| --- | --- | --- |
| Whisper | macOS 桌面打包 whisper.cpp／Metal | 模型、媒体长度和内存仍影响速度 |
| Qwen3-ASR | Apple Silicon／MLX | 本机开发试用版支持在线与离线；发行状态见路线图 |
| DFlash | Apple Silicon／MLX，配套 Qwen 1.7B 8-bit | 不是任意模型通用的加速开关；日语有当前实验记录 |
| SenseVoice／Zipformer 草稿 | 当前使用 CPU 路径 | SenseVoice 周期重识别，Zipformer 原生流式 |

适配某后端不等于所有 M 系列芯片、内存规格和语言都完成实测。不提供未经测量的芯片速度排名或统一两秒承诺。Windows 当前暂停开发。

## 系统音频权限

在线读取系统输出，需要 macOS 的系统音频录制授权。停止在线会话后停止采集，当前不保存录音。重复弹出系统授权仍在调查；不是要求用户每次手动重新配置权限的既定流程。
