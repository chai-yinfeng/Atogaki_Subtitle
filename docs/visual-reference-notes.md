# 视觉参考讨论：画集与书信

日期：2026-10-19。仅记录观察与建议，本轮不改整体样式，不下载或打包官网素材。

## 官方参考

- [幻燈特设](https://sp.universal-music.co.jp/yorushika/gentou/)：加藤隆的画集，首页以油画图像与纸白版面对照，蓝绿背景、金黄色灯光、可见笔触、窄而克制的文字。不能把开场灯具线稿的单色动画当作整套风格。
- [月と猫のダンス特设](https://sp.universal-music.co.jp/yorushika/tsukineko/)：森林、动物、月亮构成的绘画，深蓝绿与月光黄形成对比；现场影像作品以《幻燈》为题材，两者视觉有联系。
- [二人称特设](https://sp.universal-music.co.jp/yorushika/nininshou/)：信封、稿纸、邮政红色细节、暖色纸面与墨字、留白及细致的实物阴影。与当前官网首页封面属于同一作品语境，但应参考完整特设页。

## 待讨论的应用方式

“绘画／月夜”可作为收听页外围、空状态和封面的背景方向；“书信／纸页”可作为字幕阅读、学习来源列表及校对工作区的版式方向。避免每个页面分别堆满画面，保持一套信息层级和交互行为。是否做两套可切换主题尚未决定。

背景保留画面的构图和色彩关系，文字区域提供稳定、可读的底色；波形和状态色独立于背景色，颜色不能成为唯一状态提示。当前大卡片嵌套、胶囊按钮和装饰英文过多的问题，需要先整理密度与层级，不能只靠贴背景解决。

正式产品素材选择另定，参考作品不等于把官网品牌标志或原图直接纳入发行包。
