# 视觉参考讨论：画集与书信

日期：2026-10-19。仅记录观察与建议，本轮不改整体样式，不下载或打包官网素材。

## 官方参考

- [幻燈特设](https://sp.universal-music.co.jp/yorushika/gentou/)：加藤隆的画集，首页以油画图像与纸白版面对照，蓝绿背景、金黄色灯光、可见笔触、窄而克制的文字。不能把开场灯具线稿的单色动画当作整套风格。
- [月と猫のダンス特设](https://sp.universal-music.co.jp/yorushika/tsukineko/)：森林、动物、月亮构成的绘画，深蓝绿与月光黄形成对比；现场影像作品以《幻燈》为题材，两者视觉有联系。
- [二人称特设](https://sp.universal-music.co.jp/yorushika/nininshou/)：信封、稿纸、邮政红色细节、暖色纸面与墨字、留白及细致的实物阴影。与当前官网首页封面属于同一作品语境，但应参考完整特设页。

## 应用方式

“绘画／月夜”可作为收听页外围、空状态和封面的背景方向；“书信／纸页”可作为字幕阅读、学习来源列表及校对工作区的版式方向。避免每个页面分别堆满画面，保持一套信息层级和交互行为。2026-10-19 按用户反馈实现“月夜”“来信”两套整体主题。

背景保留画面的构图和色彩关系，文字区域提供稳定、可读的底色；波形和状态色独立于背景色，颜色不能成为唯一状态提示。当前大卡片嵌套、胶囊按钮和装饰英文过多的问题，需要先整理密度与层级，不能只靠贴背景解决。

正式产品素材选择另定，参考作品不等于把官网品牌标志或原图直接纳入发行包。

## 早期作品补充观察

- [だから僕は音楽を辞めた 官方专辑页](https://yorushika.com/discography/detail/6/)：暖色街巷摄影叠加白色人物线稿；手写／手绘与现实场景并置。适合提炼城市旅途、照片边框与信件注记，不照搬封面人物。
- [エルマ 特设](https://sp.universal-music.co.jp/yorushika/elma/)：日照下的绿色庭园／建筑摄影、白色手写文字，以及日记与旅行照片的实体概念。可与上一张合为“旅途日记”参考，而非简单按绿色／橙色分成两套。
- [盗作 特设](https://sp.universal-music.co.jp/yorushika/tousaku/)：旧纸、图像与乐谱拼贴，黑色文字块，书籍与录音媒介；可提炼“旧书／档案”方向。官网主视觉并非纯黑暗色主题，不能仅凭标题推导为黑色。
- [創作 特设](https://sp.universal-music.co.jp/yorushika/sousaku/)：近白细纹理、压印式标题、克制的浅青灰导航。可提炼“素纸”方向，作为没有大幅背景图的阅读基线。

## 主题系统（首批已实现）

内部把场景背景、阅读表面、控件／语义状态分层，产品入口先提供配好的整体主题。背景强度与阅读明暗暂不开放独立调整；暂不提供任意背景 × 任意文字皮肤的全组合。背景色温、明暗、阅读表面、强调色及阴影存在关系，应以组合验证。后续若要开放混搭，只展示已验证的兼容组合。

候选：月夜画集（绘画蓝绿与灯光，配冷白阅读纸面）、来信（信封／稿纸，配暖白墨字）、旅途日记（庭园／街景摄影，配中性日记页）、旧书档案（低强度拼贴与旧纸，配明确的文字层级）、素纸（近白细纹与少量青灰）。名称为应用设计提案，不是官方主题产品。

首轮已提供“月夜”“来信”；其他方向保持提案。主题只改变视觉，不改变功能布局、快捷键、时间轴手势或已保存的字幕样式。字幕导出的字体／颜色与 App 主题应独立；字号、可读性选项和减少动画不应被主题强制覆盖。首版 SVG 已由材质版替换：月夜为带颜料笔触的蓝绿山林与月光，来信为有纸纤维、折痕、实体阴影的文具场景；生成来源与提示词见 [材质资产](theme-material-assets.md)，没有打包官网原画、标志或字体。

## 作品关系与视觉差异补充

用户提供作品关系：月光／前世与《だから僕は音楽を辞めた》《エルマ》，盗作 Live 与《盗作》《創作》，月猫与《幻燈》，一人称与《二人称》。作品组关联不等于每张专辑／Live 使用相同配色和媒介。实看 Live 页面后，前世为灰绿／红花叙事插画，月光再演为深青蓝透光画面，盗作再演为暗色拼贴与紫色标题，一人称为浅白超现实空间；《二人称》特设的信封／稿纸仍单独作为来信主题参考。《幻燈》完整首页的绘画与暖黄灯光应与开场单色灯具动画区分。

本轮只深化月夜与来信；其他作品组的主题数量和推进顺序等用户检查后决定。
